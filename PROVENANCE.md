# Происхождение материалов

Название программы — «Азимут» (Azimuth), прежние рабочие названия — QCC Studio и QuAS; проверка товарного знака перед публичным выпуском не проводилась. Значок приложения (`assets/app-icon`: циферблат с азимутом стрелки на звезду) нарисован программно в SVG для этой версии.

Код этой версии создан в рамках работы с владельцем проекта по его учебным сценариям. Исходный код, изображения, значки, тексты справки и оформление Chemcraft не копировались. Спецификация интерфейса: три этапа лабораторной работы, редактирование XYZ, открытый текст входного файла и отдельная интерпретация результата. 3D-проекция и рисование атомов написаны средствами QPainter, без сторонних моделей и иллюстраций. Брендинг — текстовый.

Шаблон формата ORCA сверялся с официальной документацией. Самостоятельные тестовые структуры и синтетический пример вывода поставляются как учебные данные. Синтетические численные значения не являются эталоном физической точности.

Источники технических сведений:
- https://www.faccts.de/docs/orca/6.1/tutorials/first_steps/first_calc.html
- https://www.faccts.de/docs/orca/6.1/tutorials/prop/freq.html
- https://www.faccts.de/docs/orca/6.1/tutorials/first_steps/parallel.html
- https://doc.qt.io/qtforpython-6/

Лицензия собственного кода выбрана владельцем 2026-11-10: все права защищены; 2026-11-25 заменена академической — свободно для преподавания, обучения и некоммерческих исследований с обязательной ссылкой, коммерческое использование с письменного разрешения (файл `LICENSE` в корне, форма ссылки — `CITATION.cff`). Это не документ о юридической очистке продукта. Перед публичным выпуском нужны решение о лицензии, проверка названия и проверка соблюдения условий зависимостей для конкретной формы поставки.

## Конструктор версии 0.2

По запросу владельца ознакомились с публичным описанием работы с фрагментами и построения молекул в Chemcraft как с ориентиром пользовательского сценария:
- https://www.chemcraftprog.com/help/workwithmolfrag.html
- https://www.chemcraftprog.com/help/constrmol.html
- https://www.chemcraftprog.com/help/editmenu.html

Обработчики мыши, проекция, размещение и присоединение атомов, редактирование связей и отмена реализованы самостоятельно. Координаты пяти фрагментов созданы для этого проекта; библиотеки фрагментов и другие ресурсы Chemcraft не использовались. Геометрии являются приближёнными учебными заготовками.

## QuAIL, версия 0.3

Маскот создан встроенным инструментом генерации изображений и выбран владельцем проекта. Утверждённый лист (`assets/quail-sheet.png`) и копия пособия владельца (`web/QuAIL-course.html`, `web/QuAIL-guide.html`) удалены в 0.62.0: программа их больше не показывала.

## Интерфейс версии 0.4

Кнопки подписей, измерения и экспорт блоков координат реализованы самостоятельно. Поведение Ctrl+B сверено с публичной справкой Chemcraft: https://www.chemcraftprog.com/hints.html. Синтаксис координат ORCA сверялся с https://www.faccts.de/docs/orca/6.1/manual/_static/pdf/orca.pdf, NWChem — https://github.com/nwchemgit/nwchem/wiki/Keywords-for-the-GEOMETRY-directive. Gaussian экспортируется как блок геометрии; требуемое ключевое слово единиц указано пользователю отдельно, полный входной файл не генерируется.

## Значки версии 0.6

Векторные значки панели нарисованы самостоятельно в коде icons.py и отображаются средствами QtSvg. Изображения и значки Chemcraft не использовались.
