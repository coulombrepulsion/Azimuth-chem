# Азимут — квантовая химия: теория и расчёт

Версия 0.249.30. Учебная программа по квантовой химии: **понять теорию → построить молекулу → подготовить и запустить расчёт → разобрать результат**. Python, Qt (PySide6) и VTK.

## Разделы

| Раздел | Что делает |
|---|---|
| **Атлас** | 56 интерактивных тем теории на русском, английском и китайском; численные модели считаются в самой программе, интернет не нужен |
| **Компас** | Построение и редактирование молекул и кристаллов, 3D-модель, симметрия и название, UFF, пептиды и координационные центры, конформеры, путь реакции, проекты с наборами молекул, результаты расчёта на модели |
| **Секстант** | Входные файлы ORCA, Gaussian, Psi4, xtb, MOPAC, GAMESS (US) и NWChem с проверкой; запуск на этом компьютере или на сервере со SLURM (ORCA и MOPAC; процессы и память — из панели, по рекомендации сервера), очереди расчётов (на сервере — одним заданием) |
| **Спектр** | Результаты ORCA, Gaussian, Psi4, xtb, MOPAC, NWChem, Q-Chem, GAMESS (US) и Firefly: энергии, шаги, частоты и ИК, термохимия, орбитали и плотность |

Сами расчётные программы (ORCA и другие) в «Азимут» не входят — их ставят отдельно. Секстант умеет поставить xtb, CREST и Open MPI.

## Запуск

- **macOS (Apple Silicon)** — откройте `Azimuth.app` двойным щелчком. Приложение должно лежать в папке программы рядом с остальными файлами; для удобства сделайте псевдоним. Первый запуск ставит зависимости в локальную `.venv` и требует интернет. `Launch-macOS.command` — для установки и диагностики. Если macOS пишет «заблокирован для защиты Вашего Mac» — [README_MACOS.md](README_MACOS.md).
- **Linux (x86_64, Ubuntu 22.04+ и подобные)** — `./Launch-Linux.sh` в терминале (первый раз ставит зависимости), затем `./Launch-Linux.sh --install-desktop` — ярлык в меню приложений; подробности и системные пакеты — [установка](docs/setup/INSTALLATION.md#linux-01940).
- **Windows** — `windows_first_run.bat`, затем `Launch-Windows.bat`; подробности в [README_WINDOWS.md](README_WINDOWS.md). Проверено на Windows x64 (0.108.77, 10 ноября 2026): установка с нуля, все тесты, запуск окна, запуск и остановка программ на этом компьютере (с поддельными программами); не проверена работа с сервером — см. README_WINDOWS.md.
- **Готовая сборка** (0.166.0) — образ диска для macOS и установщик для Windows, без Python и папки программы: как их собрать и подписать — [packaging/README.md](packaging/README.md).
- Нужен Python 3.13. Проверка установки: `.venv/bin/python verify_install.py`.
- Программа без платной подписи: при первом запуске macOS и Windows предупредят о неизвестном разработчике — как разрешить запуск, в разделе [«Первый запуск»](docs/setup/INSTALLATION.md#первый-запуск-неизвестный-разработчик-2026-11-16).

Расчёты по умолчанию сохраняются в `~/Documents/Azimuth/Расчёты`.

## Тесты

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты интерфейса и 3D-модели требуют PySide6 и VTK; остальные идут и без них. Эталонные выводы программ — в `tests/data/` (наборы cclib, BSD-3-Clause).
