# «Азимут» на macOS — если система не даёт открыть программу

Программа не подписана платным сертификатом Apple, поэтому macOS при первом запуске пишет: «Файл „Azimuth“ заблокирован для защиты Вашего Mac» (или то же про `Launch-macOS.command`). Это нормально, разрешить можно одним из двух способов.

**Способ 1 — один раз для всей папки (быстрее всего).**

1. Откройте «Терминал» (Программы → Утилиты).
2. Наберите `xattr -dr com.apple.quarantine ` — с пробелом в конце.
3. Перетащите в окно Терминала папку программы и нажмите Enter.

Пометка «загружено из интернета» снимется со всех файлов сразу: и с `Azimuth.app`, и с `Launch-macOS.command`.

**Способ 2 — через настройки, для каждого файла.**

1. Дважды щёлкните `Azimuth.app` и закройте сообщение о блокировке.
2. Откройте «Системные настройки → Конфиденциальность и безопасность».
3. Внизу, в разделе «Безопасность», у строки «Файл „Azimuth“ заблокирован…» нажмите «Всё равно открыть» и подтвердите паролем.
4. Если понадобится `Launch-macOS.command`, повторите для него то же самое.

В macOS 15 (Sequoia) и новее правый щелчок → «Открыть» эту проверку больше не обходит — нужен один из способов выше.

**Дальше.**

- Запускайте `Azimuth.app` двойным щелчком. Первый запуск ставит зависимости в папку `.venv` рядом с программой и требует интернет.
- Программы для расчётов (xtb, Open MPI, Quantum ESPRESSO) ставятся из «Секстант → Расчёт → Установить программы для расчёта…» в скрытую папку `.tools` внутри папки программы. Увидеть её в Finder можно, нажав Cmd+Shift+. (точка).
- Проекты `.qcc` открываются двойным щелчком, после того как `Azimuth.app` хотя бы раз запустился из своей папки.

Подробнее: [docs/setup/INSTALLATION.md](docs/setup/INSTALLATION.md), раздел «Первый запуск».
