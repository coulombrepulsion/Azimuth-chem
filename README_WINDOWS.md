# «Азимут» на Windows

1. Нужен 64-разрядный Python 3.12 или 3.13 (проверено на 3.13; установщик сам найдёт `py -3.13`, `py -3.12`, `python` — и Python из Anaconda тоже) и короткий путь без кириллицы, например C:\work\Azimuth. Нет подходящего — установщик сам поставит Python 3.13 только для этого пользователя (без прав администратора): из файла `python-3.13…-amd64.exe` рядом с `setup.ps1`, если его туда положить (компьютер без интернета), иначе скачает с python.org (около 30 МБ) и проверит подпись Python Software Foundation. Вручную — Python 3.13 (64-bit) с https://www.python.org/downloads/windows/ (галочка «Add python.exe to PATH»); команда `py install 3.13` есть только у нового установщика Python (Python install manager), у обычного `py.exe` её нет.
2. Если получили ZIP из интернета, разблокируйте его в свойствах до распаковки
   или выполните `Unblock-File .\Azimuth.zip` для доверенного архива.
   Если появилось окно SmartScreen «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом
   случае»: программа не подписана платным сертификатом (docs/setup/INSTALLATION.md, «Первый запуск»).
3. Запустите windows_first_run.bat. Он вызывает установку, сохраняя сообщения ошибок.
4. После успешной проверки запускайте Launch-Windows.bat — окно консоли закрывается.
5. Диагностика: `.venv\Scripts\python.exe verify_install.py`.
6. Сохраните текст ошибки, если установка не завершилась.

PowerShell-вариант: `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1`.
Bypass действует только на этот процесс. Политика системы не изменяется.
Скрипты ASCII; диагностика экранирует кириллицу в ошибках. Имена каталогов
передаются отдельными аргументами, включая пробелы. Вывод pip зависит от системы.

## Что проверено на Windows

10 ноября 2026, версия 0.108.77, Windows x64, Python 3.13.16, PowerShell 5.1 в русской локали, путь
`C:\Users\<имя>\Azimuth` (латиницей), клон с GitHub:

- `setup.ps1` с нуля: окружение `.venv`, зависимости из `requirements-lock-win-amd64.txt`, проверка — 5 из 5
  (Python, зависимости, учебные файлы, Атлас, поверхность VTK).
- Тесты: все вместе — 2038 прошли, 0 упали, 69 пропущены; каждая группа отдельно (`tools/run_test_groups.py`,
  на 0.108.75) — все прошли.
- Запуск программ на этом компьютере с поддельными xtb, CREST и ORCA (файлы .cmd): поиск программы, расчёт до конца,
  «Остановить» вместе с дочерними процессами, поиск конформеров, очередь, окно расчёта, правленый входной файл.
- Окно владельцем руками: открывается, молекула в Компасе вращается, тема Атласа открывается, пример
  открывается в Спектре.
- Владельцем руками: xtb (0.108.75) и MOPAC (0.108.78) поставлены через «Установить программы для расчёта…»
  (conda-forge), на каждом посчитан расчёт; посчитан расчёт в ORCA на этом компьютере на 9 процессах (MS-MPI).

Не проверено на Windows:

- работа с сервером — SSH, отправка задач и очередей, передача файлов, VPN (около 55 тестов пропускаются: поддельный
  сервер в них — набор bash-скриптов);
- тесты установки через conda (5 тестов; сама установка xtb проверена руками) и встраивания в 3D через внешний
  Python (3 теста);
- Gaussian, Psi4, обёртка mpirun, orca_2mkl (4 теста);
- путь программы с кириллицей и запуск с другого компьютера.

Первая загрузка VTK после установки может идти минуты (антивирус проверяет его файлы) — не прерывайте её.
