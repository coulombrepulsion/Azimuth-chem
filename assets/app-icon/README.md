# Значок «Азимута»

С 0.55.0 значок — знак из левой панели программы (`glyph.svg`, `glyph-small.svg`) на плитке цвета
этой панели; вариант выбирается по теме программы, как и сама панель.

- Светлый — файлы в этой папке: плитка #f4f6fa→#e6ebf2 (фон панели в светлой теме), кромка #cfd7e2.
- Тёмный — те же файлы в `dark/`: плитка #22304a→#172133 (фон панели в тёмной теме), кромка #33435f.

`azimuth-{16…1024}.png`: 16–64 px из упрощённого `azimuth-small.svg`, 128–1024 из `azimuth.svg`;
`Azimuth.icns` (macOS; светлый лежит и в `Azimuth.app/Contents/Resources`), `Azimuth.ico` (Windows).
`azimuth*.svg` = `glyph*.svg` + плитка; PNG, ICNS и ICO сделаны из них (Chromium, 2026-10-25).

Пока программа открыта, Dock показывает значок окна; при смене темы `hub/dock_icon.py` ставит
тот же вариант на `Azimuth.app`, поэтому после закрытия в Dock остаётся значок той же темы.
