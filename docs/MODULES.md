# Азимут — квантовая химия: теория и расчёт

Полный список модулей с описаниями — docs/MODULES_INDEX.md (составляется `tools/modules_index.py`, 0.91.45).

## §1 Назначение
Четыре рабочих раздела и общий хаб. Атлас — теория, Компас — структура и
3D-анализ, Секстант — подготовка расчёта, Спектр — результаты и графики.

## §3 Сценарии
Хаб: `.venv/bin/python main.py`.
Отдельные рабочие окна: `python -m modules.compass`, `python -m modules.sextant`,
`python -m modules.spectrum`, `python -m modules.atlas` из корня программы.
На Windows используйте `.venv\Scripts\python.exe`.
Атлас отдельно открывается без адаптера хаба. Нативные модули имеют отдельные
точки запуска, но требуют общего ядра и окружения «Азимута»: это не четыре
самодостаточных установочных пакета. Перенос данных между разными процессами —
через XYZ/проект/файл результата; живой общий сеанс предоставляется хабом.

## §4 Контракт хаба
hub/modules.json (проверяет hub/registry.py): порядок разделов в панели; у каждого
id ∈ {atlas, compass, crystal, sextant, spectrum} без повторов, непустые title/en/zh/icon,
page — номер страницы Studio 0…2 без повторов, у Атласа null, у crystal — 0 (общая с compass, 0.46.0); файл
assets/navigation/<icon>.svg обязателен. Нарушение — ValueError при запуске.
Атлас (0.160.0) — на сайте: пункт «Атлас» открывает его в браузере (azimuth/site.py,
docs/features/ATLAS.md); 0.161.0: modules/atlas/panel.py и др. удалены. Ctrl+1…5 (на Mac Cmd)
переключают разделы; последний раздел и язык запоминаются. Панель — узкая полоса значков (NARROW),
названия — во всплывающих подсказках; под значком программы — «Назад» / «Вперёд» по истории разделов и тем
Атласа (StandardKey.Back / Forward); во всех разделах — бледные шкалы азимута справа вверху и секстанта слева внизу (Ornament); выдвижение панели временно выключено (PANEL_EXPANDABLE в
hub/window.py; включённое — панель поверх страницы, щелчок по странице убирает её). Значок программы
в левом верхнем углу открывает главную страницу (HOME): знак «Азимут» с девизом, приветствие Квила, что такое
программа, четыре блока разделов со ссылками, «Продолжить» (последняя тема Атласа, молекула Компаса,
результат Спектра — только названия; ключ hub_atlas_page и Studio.recent); советы Квил с 0.35.0 — на главной
Атласа (web/assets/js/tips.js: по одному на тему, [page, ru, en, zh]); запуск — с главной (или последнего раздела). Во
встроенном Атласе Квил, приветствие и девиз скрыты (setControl('greeting', false)); «О программе» —
окно хаба: девиз, версии программы, Атласа, Компаса, Секстанта и Спектра одной строкой в шапке
(`__version__` модулей; 0.55.0), что такое программа и её разделы, автор и связь, как сослаться на Атлас,
«Руководство» (docs/manual/<язык>.md; с 0.55.0 — вкладка на каждый раздел «## …») и «Журнал изменений»
(записки Квил docs/journal/<язык>.md; с 0.55.0 — вкладки «Программа», «Атлас», «Компас», «Секстант», «Спектр»:
записи раздела стоят под «### <раздел>» внутри версии, общие — сразу под «## <версия>»; к «Атласу»
добавляется его технический журнал без строк «Правки внесла»; технический CHANGELOG.md остаётся в папке программы).
Над Компасом, Секстантом и Спектром — шапка хаба: значок раздела, знак «Азимут», черта, название раздела.
Язык (RU / EN / 中文) выбирается в панели: он меняет подписи панели, язык Атласа и разделов
Компас, Секстант, Спектр (azimuth/i18n.py: tr() для текстов, locale/en.json и zh.json; смена на ходу —
retranslate по виджетам; значения-ключи списков — combo_key / set_combo_key).
Дерево тем курса — собственное меню Атласа и видно только в нём.

## §6 Ограничения
Модули независимо запускаются и редактируются по папкам, но разделяют ядро,
ресурсы, зависимости и интерфейс сеанса. Изоляция установки/плагинный API —
отдельная будущая задача. Старые ключи QSettings сохранены ради настроек пользователя.
Исходный Атлас и его архивы автора перемещаются вместе, содержимое не меняется.

## §8′ Устойчивость
Неподдерживаемый маршрут не управляет редактором. При переключении сохраняются
проект и undo, скрытая анимация останавливается. Перед выходом действует общий
диалог сохранения. Резервные версии — в Backups рядом с папкой программы; остаются три последние.
