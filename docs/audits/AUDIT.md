## Внешний аудит 0.91.65 — 2026-11-04, исправления в 0.91.66

Автор передал отчёт «Аудит архитектуры, надёжности и производительности» (другой ассистент, на его Mac, Git `0051b94`,
выборочно: 103 теста, две воспроизведённые проверки, один замер парсера). Что сделано по его пунктам:

- **R1 (высокий, воспроизведён):** после `sbatch` сбой записи `job.json` больше не превращает принятый сервером расчёт
  в «failed»: номер и папка задачи сказаны в сообщении (`RemoteJob.local_warning`, держится во всех следующих),
  наблюдение идёт до конца, повторной постановки нет; `job.json` пишется через временный файл и `os.replace`; сбой
  записи копии вывода тоже только предупреждение. Тесты `test_remote_job.py::test_a_failed_local_note_does_not_stop_the_watching`,
  `::test_job_json_is_replaced_whole`.
- **R2 (воспроизведён):** `Tasks(limit=2)` — не больше двух рабочих потоков, на ключ — один; новый запрос заменяет
  ожидающий, `cancel` снимает и ожидающий; `working()` — живые потоки, `busy()` — ожидаемые ответы. `tests/core/test_tasks.py`
  (нужен PySide6: macOS/Windows).
- **R3:** CUBE и файлы орбиталей больше 4 МБ читаются и разбираются в рабочем потоке (`read_heavy`, окно ожидания);
  поиск орбиталей в MOPAC `.aux` — заголовок и куски по 1 МБ, с памятью по размеру и времени файла (`aux_has_orbitals`;
  на 20 файлах тестов — как прежний `has_orbitals`). Задержка окна на больших файлах здесь не измерена.
- **R4:** кеш полей Компаса — не больше 16 и не больше 768 МБ массивов (`field_bytes`); CUBE разбирается NumPy из
  текста без списка строк (результаты на всех CUBE тестов и 11 искусственных случаях ошибок совпадают с прежними).
  Текст вывода в документе оставлен: без замеров не трогаем.
- **R6:** общая модель результата вынесена в `modules/spectrum/readers/results.py`; `orca.py` её переэкспортирует;
  `tests/spectrum/test_results_model.py` — модель грузится без парсера ORCA.
- **R7:** поле, посчитанное со спиннером, не показывается, если за это время сменился документ или его структура
  (остаётся в кеше, второе нажатие — сразу). Тест в `test_gui.py`.
- **R5 (архитектура окна Studio) — не начато:** большая поэтапная работа; сначала тесты поведения двух вкладок.
- **Документы:** `docs/ARCHITECTURE.md` описывает 0.64.7 — устарел (замечание отчёта верно), не обновлён.

локали, macOS Intel, Conda. Для Intel нет платформенного lock.

не установлена. Комплектные .out — учебные синтетические примеры; пользовательские
файлы с частотами по-прежнему нужны для проверки. Их нельзя выдавать за реальные расчёты.

нормировки колебаний. Для остальных модулей ещё требуется отдельная работа
над контрактами, независимыми фикстурами и проверкой численных допусков.
Массовая переделка научных алгоритмов в этой версии не выполнялась.
Полный property-based и мутационный аудит всех парсеров не выполнен.

Графический рендеринг CUBE проверялся на реальной macOS в версии 0.12.0;
в этой версии построение поверхностей проверено без окна. Драйвер Windows
