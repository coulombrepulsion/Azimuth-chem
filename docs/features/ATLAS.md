# Атлас: на сайте, программа открывает его в браузере (0.160.0; в общем окне — 0.18.0…0.159.0)

## §1 Назначение
Атлас v2 — интерактивное пособие по квантовой химии (56 тем, ru/en/zh). С 0.160.0 он живёт на сайте
azimuth-chem.com (Python-ядро считает в браузере, Pyodide); «Азимут» открывает его в системном браузере.
Папка `modules/atlas/atlas_v2` — исходник сайта (`tools/build_atlas_site.py`) и местный запуск Атласа
автором (`quas_atlas/server.py`); в собранную программу она не входит (`packaging/azimuth.spec`).

## §2 Алгоритм
1. Пункт «Атлас» левой панели (Ctrl+1) и его карточка на главной: `HubWindow.show_section('atlas')` →
   `azimuth/site.py` `open_atlas(язык)` — `https://www.azimuth-chem.com/atlas/?lang=<язык>`; окно остаётся,
   где было. `--module atlas` открывает то же.
2. «Открыть в Компасе» со страницы темы — ссылка `azimuth://compass/<ключ>` (`azimuth/links.py`):
   система передаёт её программе, молекула открывается в Компасе.
3. Руководство (`docs/manual/*.md`) ведёт ссылками на темы Атласа сайта (`#<ключ темы>`).

## §3 Применения
Теория на сайте → Компас → Секстант → Спектр; сайт помнит последнюю тему («Продолжить» в обзоре),
советы Квил — на главной Атласа сайта; режим проектора — на странице темы.

## §4 Контракт
* Расположение: `modules/atlas/paths.py` — `ATLAS_HOME = modules/atlas/atlas_v2`,
  `ATLAS_ENTRY = atlas_v2/quas_atlas/web/index.html`.
* Адреса сайта: `azimuth/site.py` — `atlas(язык, тема=None)`; тема — ключ из 1–12 латинских строчных букв
  и цифр, как `id` тем обзора; другой язык — ru.
* Страница по-прежнему объявляет `window.QuASAtlas` (версия 1) — им пользуется сам Атлас автора; программа
  его больше не вызывает (0.161.0: `panel.py`, `browser.py`, `service.py`, `app.py` удалены).
* Движок симметрии, нужный Компасу и Спектру, — своя копия программы: `azimuth/symmetry_engine` (те же
  файлы `quas_atlas/core`, равенство проверяет `tests/core/test_symmetry_engine.py`).

## §5 Процедуры
Обновление Атласа: заменить `modules/atlas/atlas_v2/quas_atlas` копией `src/quas_atlas` из проекта Атласа
(`QCСC/QuAS_Atlas_v2/quas_atlas`); если менялись файлы движка симметрии — скопировать их и в
`azimuth/symmetry_engine`; затем `python -m pytest tests/atlas tests/core/test_symmetry_engine.py` и сборка
сайта (`tools/publish_site.py`). Тесты самого Атласа (697) запускаются в его проекте.

## §6 Реализация
Атлас v2 использует только стандартную библиотеку Python; numpy ускоряет тяжёлые темы («Атомы в молекулах»,
«Проверка расчётов»), результат тот же. На сайте — Pyodide; сохранение для работы без сети — `sw.js`
(«Сохранить Атлас для работы без сети»).

## §7 Приёмка
`tests/atlas/test_atlas_server.py` — сервер пакета: главная = файл комплекта, версия, уровни водорода против
формулы Бора, занятый порт; `tests/atlas/test_atlas_contract.py` — комплект полон (56 тем × 3 языка);
`tests/atlas/test_site_build.py` — сайт; `tests/core/test_site_links.py` — адреса и ссылки руководства;
`tests/hub/test_hub.py` — «Атлас» открывает сайт, окно остаётся на месте.

## §8′ Границы
Первый расчёт крупной молекулы в «Атомах в молекулах» занимает до минуты (затем кэш). Без сети Атлас
доступен, только если его сохранили на сайте заранее. Старый сайт 0.80 (`QuAS_Атлас_сайт`) и единый HTML 0.79 остаются в папке как
материалы автора и приложением не загружаются.
