# Сравнение геометрий
## §1 Модель
Сопоставление по номеру атома: символы и число атомов должны совпадать.
Все атомы имеют равный вес. Минимизируется сумма квадратов расстояний
между соответствующими атомами переносом и собственным вращением (без отражения).
## §2 Алгоритм
Начальная структура — первый доступный цикл оптимизации; конечная — последняя
напечатанная геометрия. При отсутствии сходимости она подписана как последняя,
а не оптимизированная. Центрирование X,Y; SVD XᵀY=U S Vᵀ;
R=U diag(1,1,det(UVᵀ)) Vᵀ; X'=XR+центр(Y).
RMSD=√(Σ|X'-Y|²/N). Расстояния и углы измеряются в исходных координатах;
Δ=конечное−начальное. Для диэдра Δ приводится к [-180,180).
## §3 Применение
С 0.28.0 — в Компасе, в выдвижной панели шагов оптимизации (☰ слева от вкладки
«Молекула»). Начальная структура — геометрия входного файла, напечатанная в начале
выходного файла ORCA (`* xyz`), иначе первый цикл. Она выравнивается на выбранный
шаг и рисуется бледными атомами с пунктирными связями; тонкие точечные линии
соединяют начальное и текущее положение каждого ядра. В панели — RMSD и
наибольший сдвиг атома. Просмотр не меняет проект Компаса, пока не нажата
«Взять эту геометрию».
## §4 Контракт
Непустые конечные координаты в Å, одинаковый порядок элементов; диапазон
|координаты| ≤ 10⁶ Å. Несовпадение запрещает сравнение. Автоматического
сопоставления эквивалентных атомов, перестановки и массовых весов нет.
## §5 Код
modules/spectrum/analysis/comparison.py (align); панель — modules/compass/panels/trajectory_drawer.py, подключение — modules/compass/workspace.py.
## §6 Ограничения
При линейной/точечной структуре ориентация может быть не единственной,
но RMSD определён. Повторяющиеся элементы требуют сохранённого порядка атомов.
Связи исходного контура определяются существующей эвристикой расстояний.
## §7 Независимые проверки
Известный перенос и поворот дают RMSD около нуля; растяжение двухатомной
структуры 1→2 Å даёт RMSD 0.5 Å; отражённый неправильный тетраэдр не совпадает
с оригиналом собственным вращением. Несовпадение состава отвергается.
## §8 Ошибки
SVD float64; абсолютный допуск 1e-12 Å на малых тестовых структурах
(сотни машинных epsilon на центрирование, матрицы, SVD).
Большие координаты ограничены для предотвращения переполнения.

## Наложение другой структуры с любым порядком атомов (2026-10-23)
Отдельная функция Компаса: кнопка «Сравнить» над моделью и «Файл → Наложить
структуру для сравнения…». Сопоставление здесь автоматическое: атом одного
элемента с атомом того же элемента, один к одному, по положению; затем то же
выравнивание Кабша, что в §2 (вращение без отражения, если отражение не разрешено
явно). Чередуются два шага — назначение по элементам венгерским методом при
текущей ориентации и Кабш при текущем назначении — из набора начальных
ориентаций по главным осям облаков атомов (и поворотов при вырожденных моментах).
Метод локальный: для сильно различающихся конформеров найденное соответствие —
лучшее среди начальных ориентаций, не обязательно химически задуманное.
Контракт, алгоритм, допуски и проверки — в модуле modules/compass/chemistry/overlay.py
(§1–§8) и tests/compass/test_overlay.py; интерфейс — modules/compass/actions/overlay_actions.py.
Сравнение с начальной структурой оптимизации (§3) по-прежнему идёт по номерам атомов.
