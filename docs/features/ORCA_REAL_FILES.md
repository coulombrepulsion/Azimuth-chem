# Проверка реальных файлов ORCA — 2026-10-20

## §1 Смысл проверки
Нормальное завершение, сходимость оптимизации, SCF и полнота частот — разные
признаки. Явная аварийная остановка не должна выглядеть как отсутствие сведений.
Последняя найденная энергия прерванного расчёта не является подтверждённым
результатом завершённой оптимизации.

## §2 Алгоритм диагностики
Парсер ищет отдельную строку `ORCA finished by error termination in MODULE`;
последний такой маркер задаёт этап ошибки. Отдельно распознаются сообщения
SCF и строки MPI `Failed to get … cpu set`. Интерфейс показывает этап аварии,
не приписывая ему неустановленную первопричину. При отсутствии явного маркера
и нормального завершения статус остаётся «не подтверждено».

## §3 Проверенные данные
Пять файлов пользователя из Downloads прочитаны целиком без изменения.
Их SHA256 записаны в tests/fixtures/orca-real/sources.json. Короткие выдержки
для повторных тестов хранятся рядом; полные журналы в приложение не копируются.

| Файл (.out) | Атомы | Циклы / энергии | Итог |
|---|---:|---:|---|
| y_charged_DKH_tightopt_fixed | 25 | 56 / 57 | Нормальное завершение; оптимизация сошлась; 75 частот |
| pada_Y_neutral_local1_DKH_fixed | 54 | 17 / 16 | Ошибка LEANSCF, несходимость SCF; также сообщения MPI |
| padp_Y_neutral_new_basis_nitrate_v4_no_water_DKH_tightopt_fixed | 58 | 9 / 8 | Ошибка GUESS; сообщения MPI |
| padpa_Y_new_ver_DKH_neutral_redoing_again_tightopt_fixed | 72 | 21 / 20 | Ошибка LEANSCF, несходимость SCF; также сообщения MPI |
| y_charged_DKH_fixed | 25 | 15 / 14 | Ошибка Startup; сообщения MPI |

В четырёх аварийных файлах частоты отсутствуют. Последний цикл каждого не имеет
законченной записи энергии: программа сохраняет этот пробел, не подставляет
энергию предыдущей геометрии. Число энергий завершённого файла больше числа
циклов из-за финального расчёта энергии.

## §4 Контракт
Output.error_module — имя этапа либо None; mpi_cpu_error — наличие сообщения,
а не доказательство причины. termination_status выдаёт аварийный статус при
наличии явного маркера, иначе нормальный или неподтверждённый. Исходные признаки
normal_exit/optimization_converged/scf_failed сохраняются независимо.

## §5 Реализация
modules/spectrum/readers/orca.py разбирает журнал; workspace.py показывает статус.
Математика координат, нормировки и анимации не менялась.

## §6 Ограничения
Пять файлов не покрывают все версии и режимы ORCA. В этой выборке нет реального
расчёта с мнимой частотой; его обработка проверялась прежними синтетическими
тестами. Сообщения о CPU set встречаются и в завершённом расчёте, поэтому сами
по себе не означают аварийного завершения. Работа Windows здесь не проверялась.

## §7 Независимые проверки
Оракулы — строки и таблицы исходных журналов, числа переписаны из них вручную;
число циклов и энергий дополнительно подсчитано по заголовкам в исходном тексте.
В завершённом файле: шесть нулевых частот и 69 ненулевых мод с векторами,
69 ИК-интенсивностей, отрицательных частот нет. Мода 6: 63.43 см⁻¹,
Int = 72.36 км/моль, первый X-компонент вектора = 0.006801.
Тест отличает Int от соседних eps и T**2. Сравниваются напечатанные десятичные
значения без дополнительных преобразований, поэтому допуск не нужен.

## §8 Устойчивость
Новые поля имеют значения по умолчанию для совместимости. Неподдержанные
сообщения не выдаются за успех; сохраняются прежние ограничения размера и
запрет нескольких заданий в одном файле. Выдержка частот не содержит маркера
нормального завершения и не должна распознаваться как завершённый расчёт.
