# Сквозной путь глазами: план проверки (этап 1 плана до беты)

Последний пункт этапа 1 (`BETA_PLAN.md`), делает владелец. Цель — в `MAIN_PATH.md` у программ беты в столбцах
«Здесь: Windows» и «Сквозной путь» вместо «?» стоит «да» с версией или запись, что сломалось. Расчёты на Mac уже
пройдены без окна (сервер управления); здесь проверяется то, что видит студент.

Найденное по дороге не чинится на месте: одна строка в «Что сломалось» внизу — и дальше по плану. Чинится потом, разом.

## 0. Подготовка (10 минут)

- Версия в заголовке окна — последняя (после `git pull` на Windows).
- Новый пустой проект для проверки; старые проекты не трогать.
- «Расчёт → Установить программы для расчёта…» показывает все шесть программ беты найденными (на Windows — без CREST).

## 1. Основной сценарий — один раз на программу

Молекула — ацетальдегид (`CC=O` из SMILES в Компасе), задача «Оптимизация + частоты», настройки по умолчанию.

| Шаг | Что должно быть видно |
|---|---|
| 1. Компас: построить из SMILES, сохранить проект | молекула на экране, метил заслоняет C=O; проект появился в «Проектах» |
| 2. Секстант: выбрать программу | «Постановка задачи» без прокрутки; у ORCA, Psi4, NWChem во входном файле D3(BJ) |
| 3. «Запустить расчёт» | на месте входного файла — ход расчёта, энергия по шагам |
| 4. Конец расчёта | сообщение о конце без ошибок; мнимых частот нет |
| 5. Компас | геометрия молекулы заменилась оптимизированной; шаги оптимизации листаются |
| 6. Спектр | ИК-спектр с полосой C=O, колебание анимируется на модели, термохимия (ZPE, H, G), график сходимости |
| 7. Закрыть программу, открыть проект | результат на месте, ничего не считается заново |

Порядок и ожидаемое время расчёта на Mac:

| Программа | Метод | Время | macOS | Windows |
|---|---|---|---|---|
| xtb | GFN2 | секунды | | |
| MOPAC | PM7 | секунды | | |
| ORCA | B3LYP-D3(BJ)/def2-SVP | 1–2 мин | | |
| Psi4 | то же | 2–5 мин | | установщик не ставит (сборка conda-forge для Windows есть, не проверена) |
| NWChem | то же | 1–3 мин | | не поддерживается (сборки для Windows нет) |
| CREST | бутан (`CCCC`), поиск конформеров | 1 мин | | не поддерживается |

В клетку — «да», или номер шага, на котором сломалось.

## 2. Что должно сработать, когда не всё гладко (20 минут, только Mac)

| Проверка | Что должно быть видно |
|---|---|
| Ацетон (`CC(C)=O`) в xtb, «Оптимизация + частоты» | мнимая частота около −74 см⁻¹; кнопка «Сдвинуть по мнимой моде и оптимизировать заново»; после неё — минимум |
| Толуол (`Cc1ccccc1`) в xtb | «Маленькая мнимая частота: почти свободное вращение…», а не «не минимум»; в термохимии Спектра — то же |
| Остановить расчёт ORCA на середине | кнопка «Продолжить с последней геометрии»; расчёт доходит до конца |
| Gaussian и GAMESS в списке программ | «· не проверено», в подсказке — почему |
| Открыть любой CIF → «К расчёту кристалла» | «Постановка задачи · не проверено»; меню «Кристалл» начинается с «Не проверено…» |
| Метод HF в Секстанте | дисперсия выключилась сама; вернуть B3LYP — включилась |
| MOPAC, вода из SMILES, «Частоты и термохимия» (0.222.26) | расчёт не «успешный», а неудачный: «MOPAC не стал считать частоты: геометрия не оптимизирована» и совет выбрать «Оптимизация + частоты» |
| Кофеин из SMILES (`Cn1cnc2c1c(=O)n(C)c(=O)n2C`, 0.222.25) | формула C8H10N4O2, расчёт запускается (раньше — лишний H и отказ по чётности) |

## 3. Сервер (45 минут)

Расчёты на всех трёх серверах уже пройдены без окна (ORCA, MOPAC; CP2K и Quantum ESPRESSO на сервере 3); здесь —
окно и то, что видит студент.

**Окно «Сервер для расчётов»** (0.222.16–0.222.22)

| Проверка | Что должно быть видно |
|---|---|
| Открыть окно | только карточка «Вход»; кнопки «Проверить подключение», «Вход без пароля», «Узнать ресурсы» в ней |
| «Настройки сервера» | справа выезжает панель той же ширины, что «Вход»; окно не меняет высоту, поля не сдвигаются; заголовки «Вход» и «Расчёты на сервере» на одном уровне |
| «Окружение для» → переключать программы | подсказка в поле не накладывается на прежнюю; у программ со своими строками — «·» в списке |
| «Узнать ресурсы» | ответ под карточками (свободные ядра, память, диск, ORCA, «Вне PATH: …» — по одному пути на программу); найденные только вне PATH программы получили строку окружения; окно стало выше вниз, поля входа не сжались |
| VPN: ▶ при выключенном VPN | OpenVPN Connect не выходит вперёд (мелькает не дольше доли секунды), окно Азимута при этом нажимается; если VPN не подключился за 15 с — окно OpenVPN открывается |
| VPN: ■ | VPN отключается |

**Расчёт на сервере**

1. Ацетальдегид, ORCA, сервер 3: «в очереди» → «считается» → результат открыт в Компасе и Спектре (шаги 5–7 §1).
2. На середине расчёта выключить Wi-Fi на минуту и включить: программа не падает, состояние возвращается.
3. То же для MOPAC.
4. Сервер 1 (без SLURM, 0.222.19): расчёт запускается сразу; попросить больше ядер, чем можно, — отказ с числом
   («вместе с занятыми не больше 80 %»); «Остановить» — расчёт остановлен.
5. Компас → кристалл кремния → CP2K и Quantum ESPRESSO на сервере 3: энергия доходит до конца (через окно не проверялось).

## 4. Windows (1 час)

Основной сценарий (§1) для ORCA, xtb и MOPAC. CREST и NWChem под Windows не собираются (только через WSL — Азимут так
не умеет); Psi4 для Windows в conda-forge есть, но установщик Азимута его не ставит — «не поддерживается» в
`MAIN_PATH.md`, пока не решено иначе (2026-11-23).
Дополнительно смотреть: русские буквы в пути проекта, окно на экране ноутбука без обрезанных карточек.

- Вписать клетки в таблицу `MAIN_PATH.md` (или продиктовать — впишу).
- Этап 1 закрыт, когда у ORCA, xtb, CREST, MOPAC, NWChem и Psi4 во всех клетках «да» или «не поддерживается».
