# Первый запуск и установка: разбор к этапу 2 плана до беты

Составлено 2026-11-22 по коду (`setup.sh`, `setup.ps1`, `Launch-*`, `Azimuth.app`, `packaging/`,
`modules/sextant/install_tools.py`) и по этому Mac. Чистая установка на чужом компьютере не проверялась — это
делает владелец или первый студент. Цель этапа 2: студент ставит программу без терминала и без загрузок при первом
запуске.

## 1. Как программа попадает на компьютер сейчас

| Путь | Что нужно от студента | Терминал | Загрузки при первом запуске |
|---|---|---|---|
| **Папка с исходниками, macOS** (`Azimuth.app` → `Launch-macOS.command` → `setup.sh`) | заранее поставить Python 3.12 или 3.13 — `setup.sh` сам его не ставит и останавливается с «No Python 3.12 or 3.13 found» | открывается окно Терминала | PySide6, VTK, numpy с PyPI (сотни МБ) |
| **Папка с исходниками, Windows** (`windows_first_run.bat` → `setup.ps1`) | ничего: Python 3.13 ставится сам (с python.org или из файла рядом) | чёрное окно установки | Python и те же библиотеки |
| **Папка с исходниками, Linux** | Python и три системные библиотеки Qt через `apt`/`dnf` | да, всегда | библиотеки с PyPI |
| **Готовая сборка, macOS** (`Azimuth-<версия>-macOS-arm64.dmg`, PyInstaller) | перетащить в «Программы», один раз разрешить запуск | нет | нет |
| **Готовая сборка, Windows** (`Azimuth-Setup-<версия>.exe`, Inno Setup, без прав администратора) | один раз «Выполнить в любом случае» | нет | нет |

Вывод: цель этапа 2 для самой программы уже достигается готовой сборкой. Мешает то, что сборка не обновлялась:
в `dist/installer` лежит образ 0.166.0 от 14 ноября (сейчас 0.222.x), а сайт описывает путь с исходниками
(«при первом запуске программа сама ставит нужные компоненты — понадобится интернет»).

## 2. Расчётные программы — отдельная установка

| Программа | Как ставится | Windows | Замечание |
|---|---|---|---|
| xtb, MOPAC | «Расчёт → Установить программы для расчёта…» (conda-forge в `.tools/calc`) | да | маленькие; первое, что нужно студенту |
| CREST | там же | **нет сборки** | на Mac ставится 2.12 (у 3.0.2 ошибка окна энергий) |
| Open MPI 4.1 | там же; на Windows — MS-MPI | да | нужен только для ORCA на нескольких процессах |
| Psi4, NWChem | там же, каждый в свою папку | **не ставятся** | вместе с остальным `.tools` на этом Mac — 3,9 ГБ |
| Quantum ESPRESSO | там же | нет | вне беты |
| CP2K | Linux — там же; Mac — `brew install cp2k` | нет | на Mac нужен терминал; вне беты |
| **ORCA** | вручную: регистрация на форуме ORCA, скачать архив, распаковать, указать путь | вручную + MS-MPI | главное препятствие для студента; пошаговое «Как поставить ORCA» — в руководстве с 0.222.14 |

Менеджер пакетов (micromamba) скачивается с `micro.mamba.pm` — всегда последняя сборка, без проверки контрольной
суммы (`install_tools.py`, §6 «ASSUMPTION»). **С 0.222.27** — закреплённая версия 2.10.0 с проверкой SHA-256.

**Следствие для беты на Windows.** Из шести программ беты на Windows доступны три: ORCA (вручную), xtb и MOPAC.
CREST, Psi4 и NWChem там не ставятся (в `MAIN_PATH.md` так и записано). В окне установки на Windows их нет, но в
списке программ Секстанта они видны без пометки: считать ли их там «не поддерживается» — решить.

## 3. Где сейчас нужен терминал

1. macOS, путь с исходниками: окно Терминала при первом запуске; Python надо поставить заранее.
2. macOS: снятие карантина командой `xattr` (есть путь без терминала через «Системные настройки» — он и должен быть
   первым в инструкции).
3. Linux: всегда (для беты не критично, если студенты на macOS и Windows).
4. CP2K на Mac (`brew`) — вне беты.
5. Перенос папки: в скриптах `.venv` и в conda-окружениях записан путь (проверено 2026-11-22 при выносе из iCloud) —
   после переноса исходников нужны `sed` и переустановка программ. Готовую сборку это не касается: она хранит
   программы в `~/Library/Application Support/Azimuth` и `%LOCALAPPDATA%\Azimuth`.

- Поведение антивирусов и SmartScreen на неподписанном установщике.
