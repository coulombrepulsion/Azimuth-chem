# Задачи по программам: что есть и что можно добавить

Составлено 2026-11-21 по просьбе владельца: «пересмотри возможные новые задачи в программах (разбей по программам
главное, чтобы то, что невозможно сделать в NWChem например там не отражалось), особенно для кристаллов».

Правило, которое держат тесты: программа видит в списке «Задача» только то, для чего Секстант пишет её входной файл, а
остальное входной файл отклоняет с объяснением (`tests/sextant/test_inputs.py::test_the_tasks_of_each_program_are_the_tasks_it_writes`,
`…::test_gamess_nwchem_and_crest_are_offered_only_what_they_do`). Цепочка предлагается, только если все её шаги есть у
программы. В 0.219.0: у CREST в данных был полный список задач ORCA (и цепочки) — теперь одна задача «Поиск
конформеров (iMTD-GC)»; в окне Секстанта CREST не выбирается (он запускается из окна конформеров).

## Что программы умеют сверх этого — кандидаты

Возможности программ — по их руководствам; перед работой над пунктом сверить с руководством той версии, что стоит у
пользователей, и проверить настоящим расчётом (как частоты QE в 0.219.0: эталоны в `tests/data`). «Проверяемо здесь» —
программа стоит на Mac владельца, и тест может запустить её сам.

### Кристаллы (просьба владельца — в первую очередь)

1. **QE: фононная дисперсия и фононная плотность состояний** — сделано 0.220.0. — ph.x на сетке q, q2r.x, matdyn.x по пути зоны Бриллюэна
   (путь уже есть: `qe_paths`). Самое ценное для учёбы после частот Γ: акустические и оптические ветви, их связь с
   теплоёмкостью. Проверяемо здесь (QE на Mac). Чтение: файл частот matdyn (`flfrq`) — простая таблица.
2. **QE: проекции зон (fat bands)** — projwfc.x на расчёте bands; Спектр уже рисует PDOS. Проверяемо здесь.
3. **QE: молекулярная динамика** (`calculation = 'md'`, температура по Берендсену или Андерсену) — траектория в Компас как у
   анимации колебаний. Проверяемо здесь.
4. **QE: путь диффузии (neb.x)** — барьер перескока атома или вакансии; нужны два конца, как у NEB ORCA в Компасе.
   Проверяемо здесь, но вход neb.x — отдельный формат.
5. **CRYSTAL: зоны и DOS** (`properties`: BAND, DOSS) и **уравнение состояния** (EOS — объём от давления, модуль
   сжатия), **ИК и рамановские интенсивности** (INTENS, INTRAMAN). Программы на Mac нет — только по руководству и
   выводам с кластера владельца.
6. **CP2K: молекулярная динамика** (NVT/NPT, сильная сторона CP2K) и **NEB** (BAND). CP2K на Mac есть (conda-forge;
   для Apple Silicon сборки нет — проверить, что стоит).

### Молекулы

1. **Связанные кластеры: CCSD(T) и DLPNO-CCSD(T)** — сделано 0.221.0 (ORCA, Gaussian, Psi4; DLPNO — ORCA; только «Энергия»). — точная энергия для учебного сравнения с DFT; есть в ORCA (DLPNO),
   Gaussian, Psi4, NWChem. Сейчас в списке методов только HF, MP2, DFT и B2PLYP. Проверяемо здесь (ORCA).
2. **CREST: протонирование, депротонирование, таутомеры** (`--protonate`, `--deprotonate`, `--tautomerize`) — короткие
   флаги, тот же вывод ансамбля, что у поиска конформеров. Проверяемо здесь (CREST на Mac).
3. **Psi4: SAPT0** — разложение энергии взаимодействия на электростатику, обмен, индукцию и дисперсию; рядом с
   задачей BSSE ORCA. Psi4 ставится «Установить программы для расчёта» (0.222.0) — проверяемо здесь после установки.
4. **ORCA: ЭПР** (g-тензор, сверхтонкие константы) для радикалов; **IRC** (ORCA, Gaussian) — спуск от переходного
   состояния к реагентам и продуктам. Проверяемо здесь (ORCA).
5. **xtb: молекулярная динамика** (`--md`) — короткая траектория для анимации. Проверяемо здесь.
6. **MOPAC: IRC** — для полуэмпирики ПС. Проверяемо здесь.
