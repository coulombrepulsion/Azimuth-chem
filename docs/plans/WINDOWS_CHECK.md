# Проверка на Windows перед раздачей студентам

Один ноутбук с Windows, около часа. Цель — убедиться, что студент на Windows сам поставит программу и посчитает
молекулу; всё, что сломается, исправляется до раздачи. Расчёты на Mac и на серверах уже проверены (матрица
«программа × задача», `TASK_MATRIX.md`); на Windows последний раз проверялась версия 0.108.77 (10 ноября,
`README_WINDOWS.md`) — с тех пор изменилось очень многое.

Правило: если шаг не получился — не чинить на месте. Записать в таблицу «Что сломалось» внизу (снимок экрана, текст
ошибки) и идти дальше, если можно.

## 0. Что нужно заранее (10 минут)

| Что | Где взять | Проверка |
|---|---|---|
| Windows 10 или 11, 64-разрядная | — | «Параметры → Система → О программе»: «64-разрядная» |
| Python 3.13, 64-разрядный | python.org → Downloads → Windows; при установке отметить «Add python.exe to PATH» | в командной строке `py -3.13 --version` печатает 3.13 |
| Архив программы, версия не ниже 0.222.26 | GitHub → Code → Download ZIP (репозиторий закрытый — архив скачивает владелец и передаёт) | — |
| ORCA для Windows | orcaforum.kofo.mpg.de → регистрация → Downloads → «Windows x64» (проверена 6.1.1) | архив скачан |
| Имя пользователя Windows | — | записать, есть ли в нём русские буквы: это отдельная проверка (шаг 4.1) |

## 1. Установка (15–30 минут)

| Шаг | Что сделать | Что должно получиться |
|---|---|---|
| 1.1 | Свойства ZIP → «Разблокировать» → «Извлечь всё…» в `C:\Azimuth` (латиница, без пробелов) | папка с `windows_first_run.bat` |
| 1.2 | Запустить `windows_first_run.bat` | если SmartScreen: «Подробнее» → «Выполнить в любом случае». В конце — проверка установки, все пункты пройдены |
| 1.3 | Запустить `Launch-Windows.bat` | открывается окно «Азимут»; в заголовке или «Справка → О программе» — версия 0.222.26 или новее. Первый запуск бывает долгим (антивирус проверяет VTK) — не прерывать |

Не получилось на 1.2 — прислать файл `setup-log.txt` из папки программы.

## 2. Программы для расчёта (15 минут)

| Шаг | Что сделать | Что должно получиться |
|---|---|---|
| 2.1 | Распаковать ORCA в `C:\ORCA` | в папке есть `orca.exe` |
| 2.2 | Секстант → карточка «Запуск расчёта» или «Настройки → Программы» → указать `C:\ORCA\orca.exe` | ORCA найдена, путь показан |
| 2.3 | «Расчёт → Установить программы для расчёта…» → MS-MPI, xtb, MOPAC | по ходу — журнал установки; в конце xtb и MOPAC найдены. CREST в списке нет — так и должно быть (под Windows не собирается) |

## 3. Первый расчёт — вода (15 минут)

Компас → «Из SMILES» → `O` → вода на экране. Сохранить как новый проект. Дальше в Секстанте, задача
«Оптимизация + частоты», остальное по умолчанию.

| Программа | Настройки | Время | Частоты, см⁻¹ (на Mac, для сверки ±3) | Результат |
|---|---|---|---|---|
| xtb | GFN2 | секунды | 1539, 3644, 3653 | ✓ 1539, 3644, 3653 (xtb 6.7.1, 0.222.26) |
| MOPAC | PM7 | секунды | 1395, 2810, 2856 | ✓ 1395, 2810, 2856 |
| ORCA, 1 процесс | B3LYP-D3(BJ)/def2-SVP | 1–3 мин | 1638, 3787, 3882 | ✓ 1639, 3787, 3882 · 27 с (ORCA 6.1.1) |
| ORCA, 4 процесса | то же | быстрее, чем на одном | те же | ✓ 1639, 3787, 3882 · 18 с; энергия −76.3218532 Eh, как на одном |

После каждого расчёта:
- сообщение о конце без ошибок, мнимых частот нет;
- Компас: геометрия заменилась оптимизированной;
- Спектр: ИК-спектр, колебание анимируется на модели, термохимия (ZPE, H, G).

И ещё две проверки:
- **Остановка.** Запустить ORCA на 4 процессах и нажать «Остановить» на середине: расчёт останавливается, в «Диспетчере
  задач» не остаётся процессов `orca*.exe` и `mpiexec.exe`.
- **Повторное открытие.** Закрыть программу, открыть проект снова: результаты на месте, ничего не считается заново.

## 5. Сервер (по желанию, 15 минут)

Только если у студентов будет доступ к серверу. Сервер с Windows не проверялся никогда — здесь возможны любые сюрпризы.

| Шаг | Что сделать | Что должно получиться |
|---|---|---|
| 5.1 | В командной строке `ssh -V` | печатает версию OpenSSH (встроен в Windows 10 и 11) |
| 5.2 | VPN включить в OpenVPN Connect самому | сервер отвечает: «Сервер…» → «Проверить подключение» — «Сервер отвечает ✓» |
| 5.3 | «Вход без пароля» | откроется чёрное окно ssh — ввести в нём пароль от сервера один раз |
| 5.4 | «Узнать ресурсы» | свободные ядра, память, ORCA |
| 5.5 | Вода, ORCA, «Где считать: Сервер», 4 ядра | «в очереди» → «считается» → результат забран и открыт, как в §3 |

Кнопки VPN в окне сервера на Windows не прячут окно OpenVPN Connect (это сделано только для macOS) — оно может
выйти поверх Азимута. Это не поломка.
