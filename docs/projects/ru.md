# Проекты курса в «Азимуте»

Листы к восьми выбранным темам курса «Квантово-химические методы»: шаги плана темы и где они делаются в программе.
План темы, вопросы на защите и список «В отчёте обязательно» – в материалах курса; здесь только путь по окнам.
Названия задач, кнопок и пунктов меню даны так, как они написаны в программе (версия 0.239.0 и новее).
В конце – листы к темам, которые в этом году не выбраны (5, 7, 8, 14, 15); пошаговых планов курса к ним нет, шаги предложены здесь.

Общее для всех тем:

- Каждый расчёт остаётся в своей папке внутри проекта. Проект: «Файл → Сохранить проект».
- Абзац для раздела «Методика расчёта» и архив входных файлов: «Расчёт → Методика расчёта…» в Секстанте или
  «Инструменты → Методика расчёта…» в Спектре. Абзац собран из файлов расчёта; зачем выбран метод и как проверена
  сходимость, дописываете вы.
- График окна сохраняется кнопкой «Сохранить рисунок…» (PNG или SVG на белом фоне, оси подписаны с единицами; на вкладках Спектра – правой кнопкой мыши по графику), таблица – кнопкой «Сохранить данные…» (CSV), если график нужен свой.
- Программа не ищет литературные и экспериментальные числа за вас: источник каждого числа записываете сами.

## Кристаллы: общие шаги (темы 1–4, 6)

| Шаг | Где в программе |
|---|---|
| Структура | «Компас · Кристалл»: «Файл → Открыть CIF…» или «Файл → Найти кристалл в COD…». Файл из Materials Project открывается так же |
| Переход к расчёту | Стрелка «К расчёту кристалла» внизу Компаса: открывается Секстант с программой Quantum ESPRESSO |
| Примитивная ячейка | Галочка примитивной ячейки в строке «Ячейка» (включена, когда решётка центрированная): атомов меньше, расчёт быстрее. Энергия в сводке – на ячейку расчёта |
| Сходимость | Задачи «Сходимость по энергии обрезания» и «Сходимость по k-сетке», затем «Показать сходимость»: график ΔE, таблица с давлением и щелью, в сводке – с какого значения сошлось |
| Свои настройки | Строки «Обрезки» и «Сетка k»; заряд, спин, DFT+U, заполнение и пороги – «Дополнительные настройки…» |
| Уравнение состояния | Задача «Уравнение состояния (ряд объёмов)», затем «Показать E(V)»: a₀, B₀, B₀′ в сводке |
| Оптимизация | «Оптимизация атомов» или «Оптимизация с ячейкой»; после расчёта – «Открыть оптимизированную ячейку» |
| Зоны | Задача «Зонная структура», затем «Показать зоны»: под графиком – прямая щель или непрямая, где потолок валентной зоны и дно зоны проводимости |
| Плотность состояний | Задача «Плотность состояний», затем «Показать плотность состояний»: полная и по элементам и орбиталям |

На Windows Quantum ESPRESSO ставится из «Расчёт → Установить программы для расчёта…». Если расчёт на вашем
компьютере не запускается, считайте на сервере кафедры (переключатель «Сервер») и сообщите преподавателю.

| Шаг плана | Где в программе |
|---|---|
| 1. Кремний, 2 атома | CIF кремния (COD или `examples/10-crystals`), примитивная ячейка |

| 3. Уравнение состояния для PBE и LDA | «Уравнение состояния (ряд объёмов)» дважды: «Функционал» PBE и «LDA (Пердью – Цунгер)». Для LDA сначала «Скачать псевдопотенциалы» |

отличаться в третьем знаке, укажите файл в методике. Зоны считайте в равновесной ячейке каждого функционала (a₀ из
шага 3) либо в измеренной – но одинаково для обоих и с оговоркой в отчёте.

## Тема 3. Упругие постоянные MgO

| Шаг плана | Где в программе |
|---|---|
| 1. MgO, 2 атома | CIF, примитивная ячейка |
| 2. Сходимость по давлению | В таблице сходимости есть столбец давления; в сводке сказано, с какого обрезания оно сошлось до 1 кбар |
| 3. Уравнение состояния | «Уравнение состояния (ряд объёмов)»: a₀ и B₀. Дальше считайте в ячейке с этим a₀ (или после «Оптимизации с ячейкой») |
| 4. Черновик с MACE | В программе нет – по тетради курса |
| 5–6. Три деформации, C₁₁, C₁₂, C₄₄ | Задача «Упругие постоянные (кубический кристалл)», затем «Показать E(ε)» |
| 7. Проверка B, анизотропия, соотношение Коши | В сводке задачи: B = (C₁₁ + 2C₁₂)/3, A и C₁₂ − C₄₄ |

Что учесть. Вторая деформация в программе – растяжение вдоль x со сжатием вдоль y (ε₁ = e, ε₂ = −e, ΔE/V₀ =
(C₁₁ − C₁₂)e²), а в подсказке плана – тетрагональная diag(e, e, 1/(1+e)² − 1). Обе дают C₁₁ − C₁₂, но рабочие
формулы разные: в отчёте выводите формулы для тех деформаций, которые считали. Амплитуды в программе ±0.5, ±1 и
±1.5 %. Оценку погрешности по разбросу амплитуд делайте сами по сохранённой таблице E(ε).

## Тема 4. Графен: конус Дирака и влияние k-сетки

| Шаг плана | Где в программе |
|---|---|
| 1. Ячейка из 2 атомов, вакуум 12–15 Å | CIF графена с c = 12–15 Å. Слой программа узнаёт сама: одна k-точка вдоль вакуума |
| 2. Сходимость по обрезанию и вакууму | «Сходимость по энергии обрезания» и «Сходимость по вакууму (слой)» |
| 3. Энергия и уровень Ферми для N = 6 … 24 | «Сходимость по k-сетке»: для слоя это сетки N × N × 1 с N = 6, 8, 9, 10, 12, 15, 18, 24. В таблице – столбец уровня Ферми; сетки с N, кратным 3, отмечены зелёным |
| 4. Модель сильной связи | Выводите сами; для сравнения программа рисует её штрихами поверх зон |
| 5. Зоны Γ–M–K–Γ, окрестность K | «Зонная структура»: открываются два окна – зоны и «Конус Дирака» |
| 6. Скорость Ферми и t | В окне «Конус Дирака»: наклоны зон, v_F и t |

Что учесть. По умолчанию графен считается без размытия, и в столбце уровня Ферми стоит верхний занятый уровень.
Чтобы получить уровень Ферми, как в тетради (METAL = True), включите размытие: «Дополнительные настройки…» →
«Заполнение». График «уровень Ферми – N» стройте сами по сохранённой таблице.

| Шаг плана | Где в программе |
|---|---|
| 1. Реагенты и продукты | Компас: построение молекулы, «Расчёт → Поиск конформеров…», «Расчёт → Быстрый расчёт xtb»; Секстант: задача «Оптимизация + частоты» |
| 2. Начальное приближение переходного состояния | «Скан по выделенным атомам…» (задача «Скан ППЭ с релаксацией») или «Путь реакции (NEB-CI)» с методом GFN2-xTB в ORCA |

| 4. IRC в обе стороны | Задача «Путь от переходного состояния (IRC)»; профиль и геометрии пути открываются из результата |
| 5. Уточнение энергии | Задача «Энергия» с другим базисом и функционалом; DLPNO-CCSD(T) и экстраполяция к полному базису – в списках метода и базиса |

Что учесть. Числа симметрии и стандартное состояние в k(T) проверьте в окне диаграммы и выпишите в отчёт явно.
Сравнение с опытом (E_a = ΔH‡ + RT или + 2RT) делаете сами.

MAE» собираете сами: по одному окну сравнения на расчёт.

## Тема 13. Константа равновесия конформеров или таутомеров

| Шаг плана | Где в программе |
|---|---|

## Тема 5. NiO и DFT+U

| Шаг | Где в программе |
|---|---|
| 1. Структура NaCl, магнитная ячейка | CIF из базы; для антиферромагнетика – сверхъячейка 2 × 1 × 1 примитивной ячейки (два атома Ni) в «Перестроить кристалл (ячейки, поверхность)…» |
| 2. Без спина, ферромагнетик, антиферромагнетик | Задача «Магнитный порядок (без спина, ФМ, АФМ)»: энергии трёх состояний, моменты на атомах, щель |

## Тема 7. Фононные дисперсии NaCl и теплоёмкость

| Шаг | Где в программе |
|---|---|
| 1. Сходимость и равновесный a₀ | Общие шаги; фононы считайте при своём a₀, а не при экспериментальном |
| 2. Фононные ветви | Задача «Фононные ветви и плотность состояний»: окна ветвей и плотности состояний. Расщепление LO–TO в Γ учтено (диэлектрическая проницаемость и эффективные заряды считаются в том же расчёте) |
| 3. Теплоёмкость | Третье окно, «Теплоёмкость»: C_V(T) от 10 до 1000 К, энтропия, энергия нулевых колебаний |
| 4. Сравнение с опытом | Таблица «Сохранить данные…»; измеренную C_P(T) находите сами |

Что учесть. Программа считает фононы методом возмущений в Quantum ESPRESSO (ph.x), а не смещениями в сверхъячейке,
как phonopy; результат должен совпасть. Считается C_V при постоянном объёме, а измеряется C_P: выше комнатной
температуры разница заметна, и её надо оценить отдельно.

## Тема 8. От объёмного MoS₂ к монослою

| Шаг | Где в программе |
|---|---|
| 1. Объёмный 2H-MoS₂ | CIF из базы; общие шаги. Для расстояния между слоями включите дисперсионную поправку DFT-D3(BJ) в «Дополнительных настройках…» |
| 2. Зоны объёмного кристалла | «Зонная структура»: щель непрямая, под графиком – где экстремумы |
| 3. Монослой | «Файл → Монослой из слоистого кристалла» в «Компас · Кристалл»: один слой с вакуумом 15 Å |
| 4. Сходимость по вакууму | Задача «Сходимость по вакууму (слой)» |
| 5. Зоны монослоя | «Зонная структура»: путь Γ–M–K–Γ; щель прямая, в точке K |
| 6. Два и три слоя | «Перестроить кристалл (ячейки, поверхность)…»: пластина нужной толщины |

Что учесть. Спин-орбитальное расщепление потолка валентной зоны в K (около 0,15 эВ в монослое) в этом расчёте не
получается: он скалярно-релятивистский. Проверочный расчёт (PBE, ячейка из опыта): 0,85 эВ, непрямая, у объёмного
кристалла и 1,79 эВ, прямая в K, у монослоя. PBE занижает щель; сравнивайте с оптической щелью осторожно – в монослое
велика энергия связи экситона.

## Тема 14. Константа скорости с туннельной поправкой

| Шаг | Где в программе |
|---|---|
| 1–6. Переходное состояние, IRC, термохимия | Как в теме 9 |
| 7. Константа скорости k(T) | «Диаграмма реакции…» в Спектре: ΔG‡ и k по Эйрингу под барьером |
| 8. Туннельная поправка | Там же: κ по Вигнеру и по Эккарту; «Копировать k(T)» даёт таблицу k, κ и k·κ по температурам |
| 9. График Аррениуса | По таблице k(T): ln k от 1/T, с поправкой и без неё |

Что учесть. Обе поправки одномерны. Барьер Эккарта задан тремя числами: мнимой частотой и высотами барьера в обе
стороны с нулевыми колебаниями, поэтому на диаграмме должны быть и реагенты, и продукты с частотами. Для переноса
водорода при низкой температуре настоящая поправка может быть больше.
