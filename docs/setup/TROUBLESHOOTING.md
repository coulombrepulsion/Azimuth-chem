# Если программа не запускается

Выполните verify_install.py интерпретатором из .venv. Проверки покажут версию
Python, зависимости, целостность учебных файлов и построение поверхности.
Для короткой проверки используйте --quick.

На Windows установщик пишет весь свой вывод в setup-log.txt в папке программы,
а строка «[setup] FAIL» называет шаг, на котором он остановился (Python, .venv,
зависимости, проверка). Переустанавливать Python нужно только если остановился
шаг 1/6; при остановке на проверке смотрите строку [FAIL] verify_install.py.

Нет учебного файла («N missing: …»): архив программы неполный — скачайте его
заново. Ошибка SHA256 учебного файла: восстановите файл из той же версии программы.
Если меняете учебные примеры намеренно, обновляйте манифест при сборке;
не отключайте проверку в установщике.

Ошибка версии пакета: повторите setup.sh или setup.ps1. Существующая .venv
сохраняется, pip приводит зависимости к lock. Не запускайте через sudo.

Ошибка TLS: проверьте дату, сертификаты Python и настройки прокси. Не отключайте
проверку сертификатов. Ограничение сети отличается от отсутствия версии пакета.

Ошибка OpenGL или чёрное окно CUBE: сохраните сведения об ОС и драйвере;
успешный импорт VTK сам по себе не проверяет графический контекст.

Для диагностики установщика используйте --debug или -Debug. Логи могут
содержать ваши локальные пути; проверьте их перед публикацией.

Linux (0.194.0). «could not load the Qt platform plugin "xcb"» — нет libxcb-cursor0 (Ubuntu/Debian:
`sudo apt install libxcb-cursor0`; Fedora: `sudo dnf install xcb-util-cursor`). «Cannot create .venv» — нет
модуля venv (`sudo apt install python3-venv` или `python3.13-venv`). «No matching distribution» для PySide6 —
glibc старше 2.34 (Ubuntu 20.04, Debian 11): нужна более новая система. Модель Компаса чёрная или окно мигает
под Wayland — `QT_QPA_PLATFORM=xcb ./Launch-Linux.sh`; сохраните вывод `glxinfo -B` для отчёта.
