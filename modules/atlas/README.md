# Азимут · Атлас

Атлас v2 в папке `atlas_v2/`: пакет `quas_atlas` (страницы, Python-модели, локальный сервер) и его
CHANGELOG. Это рабочая копия; исходный проект с тестами и эталонами — `QCСC/QuAS_Atlas_v2/quas_atlas`.

Запуск отдельно из корня программы: `python -m modules.atlas` интерпретатором из .venv.
В общем окне Атлас — раздел хаба; контракт и порядок обновления: ../../docs/features/ATLAS.md.

`QuAS_Атлас_сайт/` (Атлас 0.80), `QuAS_Атлас.html` (0.79) и рабочие папки автора не загружаются
приложением и не изменяются.
