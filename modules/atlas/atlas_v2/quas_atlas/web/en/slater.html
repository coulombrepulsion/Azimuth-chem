Slater–Condon rules

The Hamiltonian matrix element ⟨Ψ|Ĥ|Ψ′⟩ between two Slater determinants reduces to a few one- and two-electron integrals. Build two determinants from spin orbitals — the program will bring them into maximum coincidence, identify the case, and write out the answer in terms of hij, Jij, and Kij.

What to understand

  • Matrix elements between Slater determinants reduce to one- and two-electron integrals by the Slater–Condon rules.
  • First bring the determinants into maximum coincidence; every column transposition changes the sign.
  • An element can be nonzero only if the determinants differ by at most two spin orbitals and have the same MS.
  • Exchange integrals arise only between spin orbitals of the same spin.
Model limits: exact rules for determinants
What is computed
Matrix elements of the Hamiltonian between two Slater determinants, in terms of hij, Jij, Kij.
Which approximations are made
Orthonormal spin orbitals; the numerical values of the integrals are not computed.
What can be concluded
The formulas are exact; an energy is obtained only after substituting the integrals of a specific calculation.

Relation between notations: ⟨ij|kl⟩ = (ik|jl), Jij = ⟨ij|ij⟩ = (ii|jj), Kij = ⟨ij|ji⟩ = (ij|ji). Spin integration kills every term in which the “incoming” and “outgoing” spins of an electron differ.

He, ⟨1s²|Ĥ|1s²⟩: why is there no exchange integral K in the answer?

The answer is 2h₁₁ + J₁₁. An exchange term exists only between spin orbitals with the same spin, and 1sα and 1sβ differ in spin — spin integration makes it vanish.

H₂: what is ⟨σg²|Ĥ|σu²⟩ equal to, and what role does it play?

Two spin orbitals differ, and the answer is K₁₂ = (12|12) — the exchange integral between σg and σu. This is the off-diagonal CI matrix element that mixes σg² and σu² and fixes the dissociation.

Single excitation 1β → 2β from the closed shell 1s²: what is the matrix element, and why is it zero for HF orbitals?

h₁₂ + (11|12) is the element F₁₂ of the Fock operator. Hartree–Fock orbitals diagonalize F, so F₁₂ = 0: Brillouin’s theorem.

|1α 2α 3β| and |3β 1α 4α|: how many transpositions, and what sign?

Number of transpositions

Move 3β from the first position to the third — two transpositions, sign +. After that, one spin orbital differs: 2α → 4α.

Are |1α 1β 2α| and |1β 1α 2α| the same determinant?

The same function up to sign: one transposition gives a factor of −1, and the element equals −E. That is why the column order must be fixed before computing the CI matrix.

Why is ⟨|1α1β||Ĥ||1α2α|⟩ = 0 even though only one spin orbital differs?

The replacement 1β → 2α changes the spin. Ĥ does not act on spin, and the spin integral ⟨β|α⟩ = 0. Only determinants with the same MS mix.
