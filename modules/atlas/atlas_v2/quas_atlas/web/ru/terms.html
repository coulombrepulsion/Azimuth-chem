Термы атомов

Одной электронной конфигурации, например 2p², отвечает несколько состояний с разной энергией — термы 2S+1L. Их находят по микросостояниям: перебираем все способы разместить электроны по спин-орбиталям с учётом принципа Паули и группируем их по ML и MS. Основной терм дают правила Хунда.

Что нужно понять

  • Одной конфигурации отвечает несколько термов 2S+1L с разной энергией.
  • Термы находят по таблице микросостояний: каждый терм занимает (2L + 1)(2S + 1) состояний.
  • Для эквивалентных электронов принцип Паули запрещает часть термов.
  • Основной терм дают правила Хунда: максимальное S, затем максимальное L, затем J по заполненности оболочки.
Границы модели: LS-связь и правила Хунда
Что вычисляется
Микросостояния конфигурации, разложение на термы, основной терм.
Какие приближения приняты
Схема Рассела–Саундерса (LS-связь); спин-орбитальное расщепление на уровни J не рассчитывается. Для конфигураций с несколькими открытыми оболочками (например, 3d²4p) правила Хунда для основного терма ненадёжны.
Какой вывод можно сделать
Набор термов точен в LS-схеме; правила Хунда предсказывают основной терм, но не порядок возбуждённых.

2. Основной терм по правилам Хунда

1) Максимальная мультиплетность: электроны занимают разные орбитали с параллельными спинами. 2) При этом максимальное L: заполняем ml от наибольшего. 3) J = |L − S|, если оболочка заполнена меньше чем наполовину, и J = L + S, если больше чем наполовину.

Сколько микросостояний у конфигурации p²?

Микросостояний

6!2! · 4! = 15: два электрона распределяем по шести спин-орбиталям без повторов (принцип Паули).

Какие термы даёт конфигурация p²?

¹D, ³P и ¹S: 5 + 9 + 1 = 15 микросостояний. Термов ¹P, ³D и ³S нет — они запрещены принципом Паули для эквивалентных электронов (сравните с 2p¹3p¹ в разделе 1).

Чему равно J в основном терме атома углерода?

J

J = 0: терм ³P₀. Оболочка 2p² заполнена меньше чем наполовину, поэтому J = |L − S| = |1 − 1| = 0.

Сколько микросостояний у конфигурации d²?

Микросостояний

10!2! · 8! = 45. Они распадаются на термы ¹G, ³F, ¹D, ³P, ¹S; основной — ³F (как у Ti²⁺ и V³⁺).

Чему равно J в основном терме атома железа?

J

J = 4: терм ⁵D₄. 3d⁶: пять электронов со спином вверх и один вниз, S = 2, L = 2; оболочка заполнена больше чем наполовину, поэтому J = L + S = 4.

Почему основной терм кислорода ³P₂, а углерода ³P₀?

У O оболочка 2p⁴ заполнена больше чем наполовину, и по третьему правилу Хунда J = L + S = 2. У C (2p²) — меньше чем наполовину, J = |L − S| = 0. Термы у p² и p⁴ одинаковые, различается только порядок уровней J.
