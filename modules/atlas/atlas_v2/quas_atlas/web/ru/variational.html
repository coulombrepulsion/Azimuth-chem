Вариационный метод и теория возмущений

Точно уравнение Шрёдингера решается лишь для немногих систем, поэтому квантовая химия опирается на два приближённых подхода. Вариационный метод даёт энергию, которая никогда не бывает ниже точной: E[φ] = ⟨φ|Ĥ|φ⟩⟨φ|φ⟩ ≥ E₀. На нём построены метод Хартри–Фока и КВ. Теория возмущений раскладывает энергию в ряд по малому возмущению; на ней основан метод MP2.

Что нужно понять

  • Вариационный принцип: энергия любой пробной функции не ниже точной энергии основного состояния, поэтому из двух функций та, у которой энергия ниже, лучше по этому критерию. Отсюда не следует, что у неё точнее плотность, дипольный момент или поведение у ядра.
  • Линейный вариационный метод (секулярное уравнение) лежит в основе Хартри–Фока–Рутана и КВ; если новый базис содержит старый, а гамильтониан тот же, энергия может только понизиться. При замене одного базиса другим или для невариационных методов (например, MP2) такой гарантии нет.
  • Теория возмущений раскладывает энергию по порядкам: E(1) — среднее возмущения, E(2) для основного состояния отрицательна.
  • Ряд теории возмущений хорош при малом возмущении и может расходиться при большом; MP2 — её второй порядок для корреляции.
Границы модели: верхняя граница энергии, а не точность всех свойств
Что вычисляется
Вариационные энергии атома H для пробных функций и базисов из гауссианов; ряд теории возмущений для ангармонического осциллятора.
Какие приближения приняты
Ограниченная пробная функция или конечный базис; ряд теории возмущений обрывается на втором порядке.
Какой вывод можно сделать
Вариационная энергия не ниже точной, но о плотности и других свойствах функции она ничего не гарантирует; ряд теории возмущений может расходиться.

2. Линейный вариационный метод: базис из гауссианов

Функцию ищем в виде φ = Σ ckgk, где gk = e−αkr², а показатели образуют геометрическую прогрессию αk = α₀βk. Минимизация по коэффициентам сводится к секулярному уравнению det(H − ES) = 0. Каждая добавленная функция (старый базис остаётся частью нового) может только понизить энергию, а все корни приближаются к точным уровням сверху (теорема Хиллерааса–Ундхейма).

3. Теория возмущений: ангармонический осциллятор

Ĥ = Ĥ₀ + λV̂, где Ĥ₀ = p²/2 + x²/2 — гармонический осциллятор с уровнями n + ½, а возмущение V̂ = x⁴. Поправки первого и второго порядка известны в явном виде; «точные» энергии получены диагонализацией в базисе из 40 функций осциллятора.

Может ли вариационная энергия оказаться ниже точной энергии основного состояния −0,5 Eh?

Нет: для любой допустимой пробной функции E[φ] ≥ E₀ — это и есть вариационный принцип. Поэтому из двух вариационных расчётов с одним гамильтонианом тот, у которого энергия ниже, лучше приближает энергию основного состояния. Плотность или дипольный момент при этом не обязательно точнее.

Раздел 2, зелёная кривая: как меняется ошибка при добавлении функций в базис?

Уменьшается, но всегда остаётся положительной: энергия подходит к точной сверху. Меньше 1 ккал/моль ошибка становится при N = 4; дальше каждая функция даёт всё меньший выигрыш.

Ангармонический осциллятор, n = 0, λ = 0,1: насколько хорошо работает теория возмущений?

Хорошо: точная энергия 0,5591, первый порядок даёт 0,575, второй — 0,5488. Оба близки, второй немного ближе.

E(1) = λ⟨0|x⁴|0⟩ = 3λ4 = 0,15. Это просто среднее значение возмущения в невозмущённом основном состоянии.

Увеличивайте λ для n = 0. Что происходит с рядом теории возмущений?

Примерно с λ ≈ 0,16 второй порядок даёт уже большую ошибку, чем первый: поправка E(2) ∝ −λ² растёт быстрее, чем уменьшается ошибка первого порядка. Ряд для x⁴ асимптотический — при любом λ > 0 он в конце концов расходится.

Пробная функция A даёт энергию ниже, чем функция B. Какая из них даёт дипольный момент ближе к точному?

По этим данным определить нельзя. Вариационный принцип ограничивает только энергию: ошибка функции первого порядка даёт ошибку энергии лишь второго порядка, а дипольный момент чувствителен к ошибке функции в первом порядке. Функция с меньшей энергией может описывать другие свойства хуже.
