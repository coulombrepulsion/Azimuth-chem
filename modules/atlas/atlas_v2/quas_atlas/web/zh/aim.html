分子中的原子：巴德理论

分子中一个原子在哪里结束、另一个原子从哪里开始？巴德理论（QTAIM）仅凭电子密度 ρ(r) 回答这个问题——这个量既可以计算，也可以通过 X 射线结构分析测量。原子是围绕原子核、由零通量面所包围的区域：没有任何一条梯度 ∇ρ 轨迹穿过这个面。这里的密度直接在浏览器中用高斯基组的 Hartree–Fock 方法计算——从最小基组 STO-3G 到 6-31G**。

需要理解的要点

  • 分子中的原子是围绕原子核、由 ∇ρ 零通量面所包围的区域；划分由密度本身决定，而不是由基组决定。
  • 临界点（∇ρ = 0）有四种类型；键临界点和键径构成分子图，各类点的数目满足关系 n − b + r − c = 1。
  • ∇²ρ 的符号表明密度在哪里集中（∇²ρ < 0）、在哪里亏损（∇²ρ > 0）；结合 ρb 和 Hb，它有助于区分共价键与闭壳层相互作用。
  • 巴德电荷是密度在原子盆上的积分，随基组增大而收敛；马利肯电荷则取决于基函数在各原子上的分布方式。
  • ρ = 0.001 表面上的静电势表明邻近分子的电荷和偶极会从哪里靠近：σ-空穴是键延长线上的正区（卤键），π-空穴位于空的或电子贫乏的 p 轨道上方（BF₃、CO₂、C₆F₆）。

1. 密度、梯度轨迹与分子图

∇ρ 轨迹（细线）来自无穷远，通常终止于原子核：在一般情况下，吸引子——密度的极大值——位于原子核处，所有到达某个吸引子的轨迹构成原子的盆。也有例外：非核吸引子（例如在某些金属和电子化合物中）以及近似密度的假象，如 STO-3G 基组中的 HF（见下方第 5 题）。不终止于原子核、而终止于键临界点的轨迹构成原子间表面——盆之间的边界（粗线）。从同一个临界点出发，有一条键径通向两个原子核——沿这条线的密度比任何相邻线上都大。

2. 三维函数与静电势

等值面是函数取同一数值的曲面。ρ = 0.001 原子单位的表面包含分子 95 % 以上的电子，通常被看作分子的“外边界”。在其上绘制分子静电势 V(r) = Σ ZA/|r − RA| − ∫ρ(r′)/|r − r′| dr′，即与单位正电荷的相互作用能。红色区域（V < 0）吸引阳离子和氢键给体，蓝色区域（V > 0）吸引阴离子和孤对电子。卤素原子共价键延长线上的正区称为σ-空穴（F₂ 也有，尽管氟是电负性最大的原子），π 体系平面上方或具有空 p 轨道的原子上方的正区称为π-空穴（CO₂、BF₃、F₂CO、C₆F₆）。拖动图像即可旋转。

3. 临界点

在临界点处 ∇ρ = 0。点的类型由 ρ 的黑塞矩阵三个本征值（曲率 λ₁ ≤ λ₂ ≤ λ₃）的符号决定：极大值 (3, −3)，通常位于原子核处；键临界点 (3, −1)——沿键径为极小、垂直于键径为极大；环临界点 (3, +1) 位于环内；笼临界点 (3, +3) 位于多面体内。各类点的数目总满足 Poincaré–Hopf 关系 n − b + r − c = 1。根据键临界点处的密度 ρb、拉普拉斯量 ∇²ρb = λ₁ + λ₂ + λ₃、椭圆度 ε = λ₁λ₂ − 1 和能量密度 Hb = Gb + Vb 判断键的性质。

4. 原子电荷：巴德、马利肯、勒夫丁

巴德原子电荷等于核电荷减去其原子盆中的电子数，即密度在原子体积上的积分。马利肯和勒夫丁电荷的求法不同：把密度矩阵分配给“归属”于各原子的基函数。因此它们取决于基组中有哪些函数、位于哪些原子上。切换基组或一次计算所有基组——表格各行会累积。

5. 按临界点划分的键类型

十二个分子在 6-31G* 基组下的全部键临界点。若 ∇²ρb < 0，密度集中在两核之间——这是共享（共价）相互作用。若 ∇²ρb > 0，键区的密度被拉向原子核；此时 Hb 的符号区分闭壳层相互作用（离子键，Hb > 0）与仍有较大共价贡献的强极性或“受张”的键（Hb < 0）。将鼠标悬停在点上可显示标注。

页面练习：先在页面上操作，再选择答案——答案会立即检查。

选择 C₆H₆（STO-3G）。一共找到多少个键临界点？

键临界点数

12 个：六个 C–C 键和六个 C–H 键。此外环中心还有一个环临界点 (3, +1)，Poincaré–Hopf 关系成立：12 − 12 + 1 − 0 = 1。

比较 N₂ 与 LiF 键临界点处的 ∇²ρ。这说明了什么？

N₂ 的 ∇²ρb ≈ −2.5 < 0：密度集中在两核之间——共价键。LiF 的 ∇²ρb ≈ +0.8 > 0，且 ρb 很小（0.07）、Hb > 0：密度被拉向原子核，这是 Li⁺ 与 F⁻ 闭壳层之间的相互作用。

C₂H₄：为什么 C=C 键的椭圆率约为 0.45，而 C–H 键几乎为零？

π 键在分子平面上下增加了密度，因此在 C=C 键临界点处，密度在垂直于键的一个方向上被明显拉长：λ₁ 与 λ₂ 差别明显。单键的密度截面几乎是圆形，ε ≈ 0；三键的截面也是圆形，因为两个 π 键合起来具有柱对称性。

H₂O，6-31G**：O 原子的电荷按马利肯还是按巴德绝对值更大？为什么？

按巴德：约 −1.2，而马利肯为 −0.67。O–H 原子间面离 H 原子很近（键临界点距它 0.2 Å），因此几乎全部成键密度都落入氧的原子盆。马利肯方法则不论电负性如何，都把重叠部分平分给两个原子。

在 STO-3G 基组中选择 HF。为什么一个键临界点也没有找到？

在最小基组中 H 原子没有自己的密度极大值：沿轴方向密度从 F 经过 H 向外单调下降。没有吸引子就没有 H 的原子盆，整个电子都“属于”氟（H 的电荷 = +1）。这是在原子核处没有尖点的高斯基组造成的假象：到了 6-31G，H 处的极大值连同键临界点一起出现。

CO 的 ∇²ρb > 0。这是否意味着 CO 中的键是离子键？

不是。键临界点处的密度很大（ρb ≈ 0.48），而 Hb ≈ −0.8——明显为负，与共价键一样。拉普拉斯量为正，是因为键临界点偏向 C 原子，落入了碳密度亏损的区域。∇²ρb 的符号只是判据之一，对极性键要结合 ρb 和 Hb 一起看。

第 2 节，静电势，F₂：在 ρ = 0.001 表面上哪里的势为正？这与氟是电负性最大的元素如何相容？

在 F–F 键的延长线上，每个原子的“顶端”：约 +56 kJ/mol，而原子周围的环带为负（约 −13）。参与 σ 键的电子集中在两核之间；沿轴在核外侧密度减少，那里的核屏蔽较弱。孤对电子位于环带中。这就是 σ-空穴；Cl、Br 和 I 的 σ-空穴明显更强，卤键 R–X···B 正是依靠它。

比较 CO₂ 和 BF₃。它们的正区在哪里？π-空穴与 σ-空穴有何不同？

CO₂ 中碳原子周围的环带为正（约 +150 kJ/mol），分子两端（O）为负（约 −67）。BF₃ 的最大值约 +185，位于硼的上方和下方，F 原子上约 −66。σ-空穴位于 σ 键的延长线上，π-空穴垂直于分子平面（或轴），在中心原子具有空的或电子贫乏的 p 轨道之处。路易斯碱正是从这一侧接近 CO₂ 和 BF₃。

C₆H₆ 和 C₆F₆（STO-3G）：环中心上方的势是什么符号？由此能得出什么？

苯环上方为负（约 −44 kJ/mol，π 电子云），H 原子为正。六氟苯正相反：环上方约 +91，氟原子上为负。两种分子的四极矩符号相反，因此 C₆H₆ 与 C₆F₆ 的混合物形成环面对面堆叠的晶体，而阴离子会结合在 C₆F₆ 环中心的上方（阴离子–π 相互作用）。

键临界点处 ρb 很大，而 ∇²ρb < 0。仅凭这一个临界点，能否断定分子在能量上是稳定的——不会放热分解为碎片？

根据这些数据无法判断。临界点描述的是给定几何构型下的密度，而稳定性是能量问题：分子与碎片的能量比较以及势能面上的极小值。在张力结构和亚稳结构中也存在键径和键临界点。
