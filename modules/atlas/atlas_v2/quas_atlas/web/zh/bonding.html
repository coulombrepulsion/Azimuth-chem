从轨道看化学键：定域化、NBO、NCI

键、孤对、杂化、给体–受体相互作用是化学家的语言。波函数本身并不包含它们：它们是解读波函数的方式。这里讲为什么轨道可以无损地旋转、分数杂化从何而来、NBO 分析中的 E(2) 意味着什么，以及 NCI 图如何找到弱接触。

需要理解的要点

  • 旋转占据轨道不改变行列式：能量和密度不变，只有轨道的样子改变。正则轨道使 F 对角化并有轨道能；定域轨道（Boys——弥散度最小，Pipek–Mezey——原子数最少）像 Lewis 结构，但没有轨道能。
  • NBO 由密度矩阵构造自然原子轨道、杂化轨道和键轨道，使占据数尽量接近 2。形式上空轨道上的剩余量衡量分子偏离单一 Lewis 结构的程度。
  • 夹角为 θ 的杂化轨道 s + λp 在 λ² = −1/cosθ 时正交：109.5°——sp³，120°——sp²，180°——sp。水（104.5°）中键为 sp⁴（20 % s），孤对各 30 % s——氧不是 sp³。
  • E(2) = −n_i F_ij²/(ε_j* − ε_i)：占据轨道向空轨道“渗入”带来的稳定化（n → σ*、σ → σ*）。这些能量不可相加，且依赖参考 Lewis 结构——是解释的语言，而非能量分解。
  • NCI：约化梯度 s = |∇ρ|/(2(3π²)^⅓ρ^{4/3})。小 ρ 处 s 也小只出现在片段之间——s 对 sign(λ₂)ρ 图上的尖峰；λ₂ < 0 吸引，λ₂ > 0 排斥；尖峰位置是强度的粗略量度。

旋转角 θ，°

把甲烷的正则轨道换成四个定域的 C–H 键轨道。什么变了？

旋转占据轨道使行列式乘以 1：可观测量不变。但定域轨道不是 F 的本征函数。

两个相同杂化轨道之间的键角为 120°。它们是什么杂化？

λ² = −1/cos120° = 2：sp²，33 % s。

在 E(2) = −n F²/Δε 中，给体与受体的能量差加倍。E(2) 会怎样？

E(2) 与 Δε 成反比。耦合 F 加倍才会使它变为四倍。

NCI 图在 sign(λ₂)ρ ≈ +0.005 处出现尖峰。这是什么？

λ₂ > 0——密度在两个方向上减小，即环点：排斥。吸引给出负值处的尖峰。
