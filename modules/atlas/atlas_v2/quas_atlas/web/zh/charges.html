原子电荷：方案比较

程序会输出“原子电荷”，但分子中原子的电荷无法测量：它取决于如何在原子之间划分电子密度的约定。不同方案的划分方式不同，对同一个波函数给出不同的数值。这里用同一个哈特里–福克计算、在四种基组下给出马利肯、勒夫丁和巴德电荷——可以看出哪些由电荷得出的结论可靠，哪些不可靠。

需要理解的要点

  • 分子中原子的电荷不是可观测量：它取决于所选的电子密度划分方式。
  • 马利肯和勒夫丁按基函数划分密度；巴德划分的是空间本身，因此随着基组增大其电荷趋于极限。在小基组中巴德电荷也会明显变化：从 STO-3G 到 6-31G**，水中氧的巴德电荷变化 0.4 e。
  • 只有在同一方案、同一基组下比较电荷才有意义：在一系列相似分子中，趋势比绝对数值更可靠。
  • 可观测量——偶极矩、静电势——可以检验电荷在多大程度上反映了分子的静电性质。
模型的适用范围：电荷是约定，而不是可观测量
计算的是什么
同一 RHF 波函数在四种基组下的马利肯、勒夫丁和巴德原子电荷；点电荷偶极矩与真实偶极矩的比较。
采用了哪些近似
不含相关的哈特里–福克方法；基组从 STO-3G 到 6-31G**；NBO、Hirshfeld 和拟合静电势的方案只作文字说明，没有计算。 在含六个笛卡尔 d 函数的基组（6-31G*、6-31G**）中，勒夫丁电荷是在先将每个这样的壳层正交归一化之后计算的，因此不依赖于分子的取向（按直接定义，NH₃ 中三个等价的 H 原子曾得到 0.2677 / 0.2692 / 0.2692）。
能得出什么结论
电荷对方案和基组的依赖有多强、哪些比较有意义——可以；原子的“真实”电荷——不行：这样的量并不存在。

用偶极矩检验

偶极矩是可观测量：它可以测量，也可以由完整的电子密度计算。如果只在原子核上放置该方案的点电荷，就得到“电荷的偶极矩” μq = Σ qARA。μq 越接近真实值，电荷对分子静电性质的描述就越好。

各方案的原理

马利肯
原子的布居是其基函数对应的对角元 (PS)μμ；重叠密度在两个原子之间平分。简单快速，但强烈依赖于基组，尤其是含弥散函数时。
勒夫丁
先对基组做对称正交化 (S1/2PS1/2)，再计算布居。不再有重叠，也就无需划分；对基组的依赖较小，但仍然存在。
巴德（QTAIM）
用密度梯度零通量面划分空间；电荷是密度在原子盆内的积分。该方案由密度本身决定，而不是由基组决定，并随基组收敛；电荷的绝对值通常更大。
其他方案
NBO（自然轨道）、Hirshfeld（自由原子密度所占份额）、由静电势拟合的电荷（CHELPG、RESP——拟合静电势，用于力场）。相互比较时应采用同一方案和同一基组。

水，6-31G**：对同一个波函数，氧的马利肯电荷和巴德电荷相差多少？

O 电荷之差，e

相差 0.55：马利肯为 −0.67，巴德为 −1.23（勒夫丁为 −0.42）。波函数是同一个，不同的只是在原子之间划分密度的规则。

STO-3G 下的 LiH：马利肯电荷中锂的符号是什么？该相信什么？

几乎为零甚至略为负（−0.02）——与化学常识相反：锂把电子给了氢，这从偶极矩（约 4.9 D）和巴德电荷（+0.84）都能看出。马利肯方案把重叠密度平分，在最小基组中会给出这样的假象。

水：在氢上加 p 函数（6-31G* → 6-31G**）。氧的马利肯电荷如何变化？为什么？

从 −0.87 变为 −0.67：新函数以氢为中心，按马利肯规则，O–H 键的部分密度现在被归给氢。而能量只改变了 0.013 Eh，偶极矩只改变 0.04 D：变的不是分子，而是记账方式。

甲烷，6-31G**：巴德和马利肯方案中碳的电荷符号分别是什么？

巴德电荷中碳为正（+0.24），马利肯电荷中为负（−0.47）。两种方案按各自的定义都是对的；“甲烷中的碳带负电荷”这一结论取决于方案，因而并不说明分子本身的任何性质。

CO，6-31G*：哈特里–福克计算的偶极矩方向与实验一致吗？

不一致。实验中 μ = 0.11 D，负端在碳上，而 6-31G* 下的哈特里–福克给出 C⁺O⁻。只有考虑电子相关才能得到正确的符号。STO-3G 中符号是对的，但纯属巧合。

水，6-31G**：巴德点电荷给出的偶极矩是多少（德拜）？为什么比真实值大？

巴德 μq，D

约 3.45 D，而由完整密度得到 2.19 D（实验 1.85 D）。原子盆本身还被极化：它们自身的偶极矩部分抵消了电荷转移，而点电荷没有考虑这一点。
