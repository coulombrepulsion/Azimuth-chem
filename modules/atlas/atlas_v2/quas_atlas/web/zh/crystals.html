晶体：晶格与晶胞

晶体是同一晶胞在三个方向上的重复。六个数——棱长 a、b、c 和夹角 α、β、γ——连同晶胞内容决定了一切：密度、原子面间距以及晶体反射 X 射线的角度。固体计算从晶胞开始，罗盘处理 CIF 文件也是如此。

需要理解的要点

  • 晶胞体积 V = abc·√(1 − cos²α − cos²β − cos²γ + 2cosα·cosβ·cosγ)；立方为 a³，六方为 a²c·√3/2。
  • 密度 ρ = Z·M/(N_A·V)，Z 为晶胞中的式单元数；用它检验解析出的结构。
  • 晶面 (hkl) 间距为 d（立方 d = a/√(h² + k² + l²)），在布拉格角反射射线：λ = 2d·sin θ。
  • 有心晶格使整组衍射消光：I 保留 h + k + l 为偶数者，F 保留 h、k、l 奇偶相同者；由消光判断晶格类型。
模型的适用范围： 理想刚性晶格，只给谱线位置不给强度
计算的是什么
由晶胞参数求体积和密度；允许衍射的晶面间距、布拉格角和多重性；立方堆积的每晶胞原子数、配位数和空间占有率。
采用了哪些近似
晶格无缺陷、无热振动；不计算强度（谱线高度为多重性）；消光只来自有心化（以及金刚石和 hcp 的基元），不含其他空间群的螺旋轴和滑移面。
能得出什么结论
晶胞如何决定密度和衍射线位置、如何由消光识别晶格——可以；完整强度需要结构因子，能量需要周期性量子化学计算。

选择 NaCl：a = 5.640 Å，Z = 4。密度是多少？

ρ，g/cm³

2.16 g/cm³：V = 5.640³ = 179.4 Å³，ρ = 4·58.44/(6.022·10²³·179.4·10⁻²⁴) = 2.16——与手册值（2.165）一致。

铜（fcc，a = 3.615 Å），Cu Kα 辐射。衍射图的第一条线在哪里？

2θ，°

43.3°——(111) 衍射：fcc 中 (100) 和 (110) 消光（指数奇偶混杂），第一个允许的晶面是 (111)，d = 3.615/√3 = 2.087 Å。

硅（金刚石晶格）：衍射图上有没有 (200) 线？

没有：金刚石在 h、k、l 全为偶数时还要求 h + k + l = 4n，而 (200) 之和为 2。因此 (111) 之后直接是 (220)。
