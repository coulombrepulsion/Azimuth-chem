晶体的缺陷与表面

真实晶体并不完美：有空位、杂质，当然还有表面。程序只能计算周期体系，所以把缺陷放进超胞，把表面放进带真空层的表面板（slab）。这里可以看到缺陷的代价、其电荷如何取决于费米能级，以及表面计算中有哪些陷阱。

需要理解的要点

  • 空位形成能：Ef = EN−1 − (N − 1)/N · EN——含空位的晶胞与同样数目原子的完美晶体比较。按键估算：Ef ≈ 2ε，即每个原子的键能。
  • 空位的平衡份额 c = e^(−Ef/kT)。Ef 误差 0.3 eV 在硅熔点附近约为八倍：计算告诉我们哪种缺陷占优，而不是有多少。
  • 带电缺陷与费米能级交换电子：Ef(q; EF) = Ef(q; 0) + q·EF。两种电荷的直线相交处为跃迁能级 ε(q/q′)，它是总能量之差，而不是轨道能量。
  • 带电超胞与其镜像及背景相互作用：修正 ≈ q²α/(2εL)，按 1/L 缓慢下降。需要数百个原子、用杂化泛函得到带隙，并尝试多个初始结构。
  • 表面是 N 层的表面板加真空：Eslab(N) = N·Ebulk + 2Aγ。体相能量取这条直线的斜率：“外部”体相能量若有误差 δ，γ 的误差为 Nδ/(2A)，随厚度增大。

硅，Ef = 3.6 eV，熔点 1687 K。空着的格点占多少？

c

e−24.8 ≈ 2·10−11：Ef/kT = 3.6/(8.617·10−5·1687) = 24.8。每 500 亿个原子一个空位——每立方厘米约 1012 个。

Ef(+; 0) = 2.9，Ef(0) = 3.4，Ef(−; 0) = 4.3 eV。能级 ε(0/−) 在哪里？

ε(0/−)，eV

0.9 eV：ε(0/−) = [Ef(0) − Ef(−; 0)]/(−1 − 0) = 4.3 − 3.4。能级 ε(+/0) = 3.4 − 2.9 = 0.5 eV：低于它缺陷是施主，高于 0.9 eV 是受主。

硅（ε = 11.7），电荷 +1，216 原子超胞。Makov–Payne 修正约为多少？

ΔE，eV

0.11 eV：L = 3·5.43 = 16.3 Å，ΔE = 2.84·14.4/(2·11.7·16.3)。0.16 eV 对应 64 个原子；修正按 1/L 缓慢下降。1.5 eV 是 ε = 5、电荷 2 的氧化物的值。

体相能量取自单独计算，每个原子误差 δ。随着表面板变厚，表面能误差如何变化？

增大：Δγ = Nδ/(2A)——误差 δ 乘以表面板中的原子数。所以体相能量取自用相同参数计算的直线 Eslab(N) 的斜率。
