电子密度

密度 ρ(r) = Σ Pμνχμ(r)χν(r)——与轨道和原子电荷不同，它是可观测量：可以用 X 射线衍射测量。这些图基于 STO-3G 基组下收敛的 RHF 计算（与 SCF 选项卡中相同的 H₂ 和 HeH⁺），所取平面包含键轴。将光标悬停或轻触图上某点，即可查看该点的数值。

需要理解的要点

  • 电子密度 ρ(r) 是可观测量：可以测量（X 射线结构分析），也可以计算。
  • 形变密度 Δρ 显示成键时电子如何重新分布。
  • 在巴德理论中，依据临界点判断键型：∇²ρ 的符号表明密度是否集中在两核之间。
  • 静电势显示带电试剂会从哪里靠近。

检验你的知识

页面练习：先在页面上操作，再选择答案——答案会立即检查。

平衡 R 下的 H₂：键临界点处 ∇²ρ 的符号是什么，意味着什么？

∇²ρ ≈ −0.84 < 0（ρ = 0.256）：密度集中在两核之间——按巴德的观点是共价键。正的拉普拉斯量是闭壳层相互作用的特征。

拉伸 H₂。键临界点处的 ∇²ρ 如何变化？

它变为正（约从 3.4 bohr 起）：原子之间的密度不再集中，类似闭壳层相互作用——原子几乎不再成键。

压缩 H₂。为什么强烈压缩时键临界点消失？

在约 1.0 bohr 以下，两核处的密度极大值合并，ρ 沿轴不再有极小值。这部分是高斯基组的特性：它在原子核处没有尖点。

H₂ 的形变密度：电子在哪里增加、在哪里减少？为什么核本身处的密度也会增加？

在键上和核附近增加，在分子外侧减少。核处增加是因为分子函数比原子函数更紧缩（ζ = 1.24 对比 1）。Δρ 的积分为零。

平衡 R 下的 HeH⁺：为什么在最小基组中没有键临界点？

H 上电子太少，在高斯基组中它没有自己的密度极大值——临界点大约从 1.74 bohr 才出现。精确密度在每个原子核处都有极大值（尖点），所以这是基组的局限，而不是分子的性质。

H₂ 的静电势：哪里为负？

只在赤道平面远处，距轴约 2.3 bohr 以外（约 −0.003 a.u.）——这是四极矩的体现。沿轴方向势为正。阳离子 HeH⁺ 处处 φ > 0。
