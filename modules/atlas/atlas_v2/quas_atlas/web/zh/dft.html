密度泛函方法

在科恩–沈方法中，能量 E = Ts + Vne + J[ρ] + Exc[ρ]，其中 J 是电子云自身的经典排斥，而 Exc 要修正其余一切。精确的 Exc 是未知的。这里有三个已知精确答案的问题——从中可以看出近似泛函错在哪里，以及为什么需要杂化泛函。

需要理解的要点

  • 在 DFT 中能量是密度的泛函；各种近似（LDA、GGA、杂化泛函）的区别在于交换相关部分。
  • 自相互作用误差：在 LDA 中电子部分地排斥自身。
  • 精确的 E(N) 是分段线性的，斜率跳变就是基本能隙 I − A = (εLUMO − εHOMO) + Δxc；LDA 和 GGA 的 E(N) 是凸的（离域误差），且没有 Δxc。
  • 精确交换的比例能减小这一误差，但不能完全消除。

1. 氢原子：自相互作用误差

单个电子没有电子间排斥，因此应有 Ex = −J 且 Ec = 0。对精确密度 ρ = e−2rπ：J = 516 = 0.3125。在哈特里–福克方法中交换恰好抵消 J。近似泛函只能部分抵消它——剩余部分就是自相互作用误差。

J（电子与自身电子云的排斥）ExEc◆ J + Ex + Ec——应为 0

2. 分数电子数：E(N) 应为折线

分数 N（H⁺、H 和 H⁻ 的统计混合）下的精确能量在整数 N 之间是线性的，斜率 dEdN 等于最高占据轨道的能量。N = 1 左侧斜率应为 −I = −0.5，右侧为 −A = −0.0277：N = 1 处的跳跃就是基本带隙。不要把它与轨道带隙混淆：在精确的 Kohn–Sham 理论中 I − A = (εLUMO − εHOMO) + Δxc，其中 Δxc 是交换相关能对电子数导数的不连续（N 越过整数时，势 vxc 本身突然平移 Δxc），因此即使精确的 KS 带隙通常也小于 I − A。计算：H 原子的 1s 上有 N 个电子，在每个 N 下优化指数 ζ。

3. H₂⁺：离域误差

H₂⁺ 只有一个电子，因此 Hartree–Fock 在这里是精确的（在最优 ζ 的 STO-3G 基组内）。核间距拉开时，精确能量趋于 E(H) = −0.5。对称的离域密度本身是允许的：在极限下，“电子在一个原子上”与“每个原子上各半个电子”两种描述应当简并。具有凸 E(N) 的泛函的错误在于另一点：两个半电子给出 2·E(½)——低于正确极限，即泛函人为地偏好分数电荷。

检验你的知识

页面练习：先在页面上操作，再选择答案——答案会立即检查。

LSDA 中的 H 原子：相关能应该是多少，实际得到多少？

单个电子没有相关，精确值 Ec = 0。LSDA 给出 Ec = −0.022，而交换 Ex = −0.268，而不是 −0.3125：电子“排斥自身”约 58 kJ/mol。

为什么对于 H 原子，“不考虑自旋的 LDA”比 LSDA 更差？

单个电子的 ρβ = 0，体系完全自旋极化。非极化电子气的公式把密度在两种自旋间平分，给出 Ex = −0.213——自相互作用误差几乎大三倍。

LSDA，a = 0：H 原子的 εHOMO 与电离能相比如何？

εHOMO ≈ −0.27，而 I = 0.5：Koopmans 定理对 LDA 不成立。原因是 E(N) 向下凸：N → 1⁻ 时的斜率绝对值小于割线斜率。因此 LDA 和 GGA 的轨道能不能用作电离势。

N = 1 处 E(N) 的精确斜率跳变就是基本能隙 I − A。它与 Kohn–Sham 轨道能隙有什么关系？

在精确理论中 I − A = (εLUMO − εHOMO) + Δxc：即使精确的 KS 带隙也比 I − A 小一个 Exc 对电子数导数的不连续 Δxc（势 vxc 也突然平移同样的量）。对于光滑的近似泛函（LDA、GGA），Δxc = 0，E(N) 斜率的跳跃就等于其轨道带隙（这里 LSDA 为 0.17，精确值为 0.472）。

R = 10 bohr 的 H₂⁺：LSDA 认为哪种描述更有利，为什么这是错误？

离域的：σg 为 −0.549，而在一个原子上为 −0.473，尽管在此基组中精确极限为 −0.495。在精确理论中两种描述在该极限下是简并的，而 LSDA 人为地压低了分数电荷的能量：2·E(½) < E(1)。误差约 140 kJ/mol。

拖动精确交换比例 a。E(N) 的曲率和 H₂⁺ 的误差如何变化？

曲率和离域误差减小：精确交换使 E(N) 向上凸，LSDA 则向下凸。当 a = 0.25（25 % 精确交换，与 PBE0 相同；这里与 LSDA 而非 PBE 混合）时 E(½) − ½E(1) = −0.037 而不是 −0.050，H₂⁺ 在 R = 10 bohr 处的误差为 118 kJ/mol。即使 a = 1 仍残留 LSDA 相关的自相互作用。
