双原子分子的分子轨道能级图

分子轨道由原子轨道线性组合（LCAO）构成。对称性相同、能量相近的轨道相互组合，电子按泡利原理和洪特规则填入 MO。由能级图可直接得到键级和磁性。能量来自一个简单模型（价层基组中的扩展休克尔方法），因此能级图是定性的。

需要理解的要点

  • 分子轨道由对称性相同、能量相近的原子轨道组成：成键轨道低于原来的原子轨道，反键轨道高于它们。
  • 键级 成键 − 反键2 与键长和键强相关。
  • σ2p 与 π2p 的能级次序由 s–p 混合决定：B₂–N₂ 中混合强，O₂ 和 F₂ 中弱。
  • 简并分子轨道上的未成对电子解释了 O₂ 和 B₂ 的顺磁性。

O₂：有几个未成对电子？

未成对电子

2：共十二个价电子，最后两个以平行自旋分别占据两个简并的 π*2p 轨道（洪特规则）。因此 O₂ 是顺磁性的——液氧会被磁铁吸引。用 O=O 双键的价键法无法解释这一点。

O₂⁻ 的键级是多少？

键级

1.5：(8 − 5) / 2。新增的电子进入反键 π* 轨道，键长从 1.21 Å 增加到 1.35 Å。

选择 B₂ 并关闭 s–p 混合。B₂ 的磁性会是怎样的？

抗磁性：没有混合时 σ2p 位于 π2p 之下，最后两个电子在 σ2p 上配对。实验表明 B₂ 是顺磁性的（光谱项 ³Σg−）——这是 s–p 混合的直接证据。

电离 O₂ → O₂⁺ 时键的强度如何变化（与 N₂ → N₂⁺ 比较）？

O₂ 失去的是反键 π* 轨道上的电子：键级从 2 增加到 2.5，键变短（1.208 → 1.116 Å）、变强（D₀ 5.12 → 6.66 eV）。N₂ 失去的是成键 σ2p 上的电子，键减弱（键级 3 → 2.5）。

CO：HOMO（σ2p）主要定域在哪个原子上？

在碳原子上：按 MO 组成，约 70 % 来自 C 原子的 2s 和 2pz。这是碳的孤对电子，因此 CO 通过 C 原子而不是 O 原子与金属配位。

C₂ 的键级是多少？

键级

2：八个价电子 (σ2s)² (σ*2s)² (π2p)⁴。两对成键电子都是 π 键，没有“纯粹”的 σ 键；这是 s–p 混合的结果之一。
