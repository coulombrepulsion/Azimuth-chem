计算误差：从方法误差到结论

没有误差的计算数值不是结果。这里讲方法、基组和收敛的误差如何相加，如何从测试集上的平均误差得到自己所求量的区间，等键反应和相关体系如何抵消误差，以及为什么构象比例对误差如此敏感。

需要理解的要点

  • 独立误差按平方相加：σ = √(σ²_方法 + σ²_基组 + σ²_收敛)。总误差由最大项决定，因此数值误差应比方法误差小数倍——那样它就看不出来。
  • 方法误差取自测试集（GMTKN55、S66）——取与你的量同类的。MAE = 0.80σ，σ = 1.25·MAE；95 % 的误差在 ±2σ 内：MAE 8 kJ/mol → ±20。此时速率常数的不确定因子为 e^{2σ/RT} ≈ 3000。
  • 等键反应左右两边每种键的数目相同，按键的系统误差相互抵消。经 C₂H₅OH + CH₄ → CH₃OH + C₂H₆ 得乙醇生成焓：−232.9 kJ/mol，实验 −234 ± 2。
  • 用相关体系校正：ΔE_校正 = ΔE_目标 + (ΔE_参考^实验 − ΔE_参考^计算)，σ² = 2σ²(1 − ρ)。相似的反应（ρ = 0.8）把误差从 8 降到 5 kJ/mol，不相似的（ρ = 0）则升到 11。
  • 通向可观测量的最后一环是指数。构象间 ΔG = 2 ± 4 kJ/mol，第二个构象的比例在 8 % 到 69 % 之间：计算无法说明哪个为主。另一常见校正是标准态：1 atm → 1 mol/L 对每个粒子给出 RT ln 24.5 = 7.9 kJ/mol。

为什么经等键反应得到的乙醇生成焓比经原子化更准确？

经原子化时八根键的误差累加（按讲座约定数值为 24 kJ/mol），在等键反应中则相互抵消。

计算给出两个构象间 ΔG = 2 ± 4 kJ/mol。诚实的表述是什么？

指数把 ±4 kJ/mol 变成 8–69 % 的区间。对单个能量差用更精确的方法可缩小区间：σ = 1 时为 23–40 %。
