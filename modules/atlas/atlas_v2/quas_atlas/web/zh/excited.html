激发态与光谱

吸收光时，电子跃迁到更高的轨道，这比原子核移动快得多。因此跃迁是垂直的，光谱中的谱带不是一条线，而是一组振动跃迁。这里可以看到谱带形状和斯托克斯位移从何而来，单重态与三重态有何区别，以及如何把计算得到的激发能和振子强度变成光谱。

需要理解的要点

  • 电子跃迁比原子核运动快：跃迁是垂直的（弗兰克–康登原理），振动谱线的强度由振动波函数的重叠决定。
  • 激发态平衡构型的位移（黄–里斯因子 S）决定谱带形状和斯托克斯位移 2Sħω。
  • 计算给出垂直激发能和振子强度；应将其与谱带最大值比较，而不是与 0–0 跃迁比较。
  • 同一组态的单重态和三重态相差 2K；它们之间的跃迁是自旋禁阻的。
模型的适用范围：位移谐振子
计算的是什么
吸收和发射振动谱带的形状、斯托克斯位移、单重态–三重态分裂；由计算得到的激发能和振子强度绘制光谱。
采用了哪些近似
一个振动模式，两个态频率相同；只考虑平衡位置的位移；从 v = 0 能级吸收（低温）；宽度相同的高斯展宽。
能得出什么结论
谱带为何宽、振动级数和斯托克斯位移从何而来、如何把计算与实验比较——可以；真实光谱的准确形状——不行。

单重态与三重态

有两个未成对电子的激发组态给出单重态和三重态。轨道相同时，它们的能量相差 2K，K 为两个轨道的交换积分（见“泡利原理”页面）。S₀ → T₁ 跃迁是自旋禁阻的，因此三重态主要通过从 S₁ 的系间窜越而布居，其发射——磷光——很慢。

令 S = 0。吸收和发射光谱是什么样子？为什么？

只剩下一条 0–0 谱线，吸收和发射共有，没有斯托克斯位移。S = 0 时激发态的平衡构型与基态相同，v = 0 振动波函数相同，与其他能级的重叠为零。

S = 2.5：吸收中哪个振动跃迁 0 → v 最强？

最强跃迁的 v

v = 2：弗兰克–康登因子服从泊松分布 e−SSv/v!，S = 2.5 时在 v = 2 处最大（0.257），v = 3 为 0.214。因此谱带最大值位于 0–0 跃迁之上。

S = 1，ħω = 1500 cm⁻¹：吸收和发射最大值之间的斯托克斯位移是多少？

斯托克斯位移，cm⁻¹

2Sħω = 3000 cm⁻¹（0.37 eV）。吸收垂直到达激发态曲线的高处，发射在振动弛豫之后垂直到达基态曲线的高处；两次各损失 Sħω。

为什么荧光光谱看起来像吸收光谱的镜像？

发射从激发态的 v = 0 能级开始，吸收从基态的 v = 0 能级开始；频率相同时弗兰克–康登因子相同，振动级数相对于 0–0 跃迁对称。镜像对称被破坏，说明频率不同或势能形状发生了变化。

S₁ 位于 3.0 eV，交换积分 K = 0.5 eV。T₁ 在哪里？磷光的波长是多少？

磷光波长，nm

T₁ = 3.0 − 2·0.5 = 2.0 eV，磷光约 620 nm——明显比荧光（413 nm）更红。2K 的估计针对的是同一组态、轨道相同的情况。

“来自输出文件的光谱”部分：在假设示例中，最低的跃迁是 4.20 eV（295 nm）。它能作为包络线的最大值看到吗？

看不到：它的振子强度为 0.02——比 5.10 eV 的跃迁小 20 多倍，只形成一个肩峰。长波谱带不是由能量最低的跃迁决定，而是由强度最大的跃迁决定；禁阻跃迁在光谱中几乎看不见。
