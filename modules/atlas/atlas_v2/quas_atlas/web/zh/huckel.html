休克尔方法

平面共轭分子的 π 电子体系：每个原子提供一个 p 轨道，库仑积分 α、相邻原子间的共振积分 β（β < 0），忽略重叠。选择一个分子或自行搭建；点击原子可改变其类型（C → N → O），点击能级可显示对应轨道。

需要理解的要点

  • 在 Hückel 方法中 π 体系只由原子的连接方式决定：原子上为 α，相邻原子之间为 β。
  • 分子轨道系数给出电荷、键级、离域能和反应活性指数。
  • 4n + 2 规则来自 Frost 圆上能级的填充。
  • 电荷（电荷控制）与前线轨道（轨道控制）可能指向不同的反应中心。
  • 电负性 χ = (I + A)/2 和硬度 η = (I − A)/2 是能量对电子数的导数；福井函数 f⁺ 和 f⁻ 指出分子在何处接受或给出电子——在休克尔方法中即 LUMO 和 HOMO 密度。

全局指数与福井函数

把能量作为电子数的函数 E(N)，用过 E(N − 1)、E(N)、E(N + 1) 的抛物线近似，即用电离能 I 和电子亲和能 A。其斜率为化学势 μ = −χ，曲率为硬度 η。

检验你的知识

页面练习：先在页面上操作，再选择答案——答案会立即检查。

丁二烯：比较 1–2 和 2–3 的 π 键级。这对键长说明了什么？

2–3 π 键级

p₁₂ = 0.894，p₂₃ = 0.447：中间的键具有部分双键性质。估算键长为 1.356 和 1.437 Å——两端的键比乙烯中的长，中间的键比单键短。离域能 0.472β。

烯丙基：切换电荷 +1、0、−1。能级有何变化？原子上的电荷又有何变化？

能级不变（α + 1.414β、α、α − 1.414β），只有非键 MO 的占据数改变。该轨道在中心原子上有节点（两端系数为 ±0.707），因此阳离子的 +0.5 电荷和阴离子的 −0.5 电荷只分布在端位原子上。

苯与环丁二烯：比较离域能以及弗罗斯特圆上能级的填充情况。

苯：6 = 4n + 2 个电子，所有成键 MO 均被填满，离域能 = 2β。环丁二烯：4 = 4n，两个电子位于能量为 α 的简并轨道对上，离域能 = 0，按休克尔方法为双自由基（反芳香性）。

环戊二烯基：什么电荷能使体系具有芳香性？比较阳离子和阴离子。

阴离子：6 个 π 电子，闭壳层，离域能 = 2.472β——这就是环戊二烯酸性较强的原因。阳离子：4 个电子，简并轨道对半充满，有两个未成对电子。

萘：亲电试剂和自由基会进攻哪里？哪根键最短？

进攻 α 位（1、4、5、8）：HOMO 密度 0.181，而 β 位为 0.069；自由价 0.453，而 β 位为 0.404。最短的键是 1–2（p = 0.725，≈ 1.387 Å）。

薁是萘的同分异构体。观察分子图：它的偶极矩从何而来？

五元环带负电（C1 和 C3 上为 −0.173），七元环带正电（C4 和 C8 上为 +0.145，C6 上为 +0.130）：相当于环戊二烯基阴离子与䓬鎓阳离子的组合。亲电试剂进攻 C1/C3，亲核试剂进攻七元环。

丙烯醛的亲核进攻：比较“前线轨道”和“π 电荷”两种判据。

按 LUMO 判断——C3 原子（c² = 0.431），即 1,4-加成，是软亲核试剂的典型反应。按电荷判断——羰基碳 C1（q = +0.333），即硬亲核试剂的 1,2-加成。两种判据分别描述反应的轨道控制和电荷控制。

选择苯，点击原子 1，把它变成吡啶型氮。电荷如何变化？亲核试剂现在会进攻哪里？

氮上为 −0.195，C2/C6 上为 +0.077，C4 上为 +0.050，C3/C5 上几乎为零。亲核试剂进攻 2 位和 4 位，亲电试剂（按电荷）进攻 3 位：吡啶正是如此。

“全局指数”：表中哪个原子的马利肯电负性最大，其硬度是多少？

氟：χ = (17.42 + 3.40)/2 = 10.41 eV，η = (17.42 − 3.40)/2 = 7.01 eV——电负性最大，也是最硬的原子之一。氯电负性较小、较软（η = 4.68 eV）。

丙烯醛 CH₂=CH–CH=O 的福井函数：按最大 f⁺，亲核试剂进攻哪个原子？

Cβ：f⁺ = 0.43，而羰基碳为 0.33。这是共轭（迈克尔）加成；软亲核试剂进攻 Cβ，硬亲核试剂进攻羰基碳（电荷控制）。
