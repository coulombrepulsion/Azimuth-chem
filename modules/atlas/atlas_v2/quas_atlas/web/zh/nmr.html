NMR：从屏蔽到化学位移

具有磁矩的核在磁场 B₀ 中以拉莫尔频率进动。核周围的电子使磁场略微减弱——即屏蔽，因此同一分子中不同原子的共振频率略有不同。程序计算屏蔽常数 σ（GIAO 方法），化学位移 δ 则由参比物——用同一方法计算的四甲基硅烷——的 σ 减去得到。

需要理解的要点

  • 拉莫尔频率 ν₀ = γB₀/2π：¹H 为每特斯拉 42.58 MHz，“400 MHz”谱仪的磁场为 9.4 T。
  • 位移 δ = σ(TMS) − σ，以百万分之一（ppm）表示，与磁场无关；参比必须与分子用相同的方法和基组计算。
  • n 个等价的自旋 ½ 相邻核产生 n + 1 条谱线，强度符合帕斯卡三角；以赫兹表示的裂分 J 与磁场无关。
  • 好的 DFT 计算对 ¹H 精确到 0.1–0.3 ppm，对 ¹³C 精确到 2–5 ppm；溶剂和构象对位移的影响与此相当。
模型的适用范围： 孤立分子，一级谱
计算的是什么
给定磁场下各核的拉莫尔频率；由计算的屏蔽 σ 和参比（或线性标定）得到的位移 δ；一级多重峰与谱图形状。
采用了哪些近似
一级裂分（J 远小于频率差）；所有相邻核等价且 J 相同；洛伦兹线型；屏蔽直接取自你的计算。
能得出什么结论
σ、δ、磁场和 J 之间的关系以及如何阅读计算谱——可以；二级谱、交换、构象平均和溶剂效应在此不作模拟。

把磁场设为 14.1 T。质子在什么频率共振？

¹H 频率，MHz

600 MHz：ν = 42.577·14.1 = 600 MHz。谱仪按质子频率命名：“600 MHz”即 14.1 T。

乙醇的 CH₃ 多重峰：甲基有两个 CH₂ 相邻氢。谱线强度比是多少？

1:2:1 三重峰：n = 2 个相邻核给出 n + 1 = 3 条谱线，系数为帕斯卡三角的一行。

J = 7 Hz，n = 2，300 MHz 谱仪：三重峰宽度是多少 ppm？

宽度，ppm

0.047 ppm：宽度 2J = 14 Hz，14/300 = 0.047 ppm。在 600 MHz 下同一宽度只占一半，0.023 ppm，所以强场中多重峰不重叠。

“自己的计算”：σ(TMS) = 31.9 ppm，某质子 σ = 24.6 ppm。这是什么质子？

δ，ppm

δ = 31.9 − 24.6 = 7.3 ppm——芳香质子区（苯 7.3 ppm）：π 电子的环电流使环外质子去屏蔽。
