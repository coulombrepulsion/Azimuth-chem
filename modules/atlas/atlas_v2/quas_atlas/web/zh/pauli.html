泡利原理与交换空穴

一维箱中的两个电子，各自处于自己的轨道 φn(x) = √2·sin(nπx)。左图：第一个电子在 x₁ 处、第二个电子在 x₂ 处的概率分布图。右图：当第一个电子固定在 x₁ 时，第二个电子会出现在哪里（可在图上或用滑块移动 x₁）。

需要理解的要点

  • 电子波函数对交换是反对称的：Ψ(1, 2) = −Ψ(2, 1)。
  • 由此得到 Pauli 不相容原理：两个自旋相同的电子不能占据同一轨道。
  • 自旋相同的电子即使没有排斥也相互回避——这就是交换（费米）空穴。
  • 因此同一组态中三重态通常低于单重态（Hund 规则）；两者之差由交换积分 K 决定。

电子排斥能：J 与 K

J 是库仑积分：电子云 φa² 与 φb² 之间的排斥。K 是交换积分，它没有经典对应，源于反对称性。这里的排斥是一维的且经过平滑处理，因此数值本身只是示意性的；重要的是它们之间的相对关系。

库仑空穴：组态混合

φ₁ 上两个电子组成的单重态是一个行列式 |φ₁φ̄₁|，与 Hartree–Fock 中相同。其中两个电子自旋相反，该函数中它们的瞬时位置没有关联：没有库仑空穴。但平均库仑排斥是计入的——它包含在平均场中并决定轨道形状。再加入第二个组态：

检验你的知识

页面练习：先在页面上操作，再选择答案——答案会立即检查。

选择“三重态”并令 φa = φb。看到了什么？为什么？

Ψ ≡ 0：三重态的空间部分是反对称的，当两个轨道相同时恒等于零。同一轨道上两个自旋相同的电子——这是泡利原理所禁止的。

MS = 0 的三重态：两个电子自旋不同。在 x₂ = x₁ 处是否有凹陷？

有，c(x₁) = 0。凹陷由反对称的空间部分决定，而三重态的三个分量的空间部分完全相同。

对 φ₁ 和 φ₂ 比较单重态与三重态的排斥能。为什么三重态更低？

三重态低 2K：自旋相同时空间函数是反对称的，电子相互回避（交换空穴），排斥更小。这是 Hund 规则的基础。

打开“带符号的 Ψ”，分别对三重态和单重态按 P₁₂。结果有何不同？

三重态的所有颜色都变为相反：P₁₂Ψ = −Ψ。单重态的图像不变：空间部分是对称的，反对称性由自旋因子提供。

CI 模块：在 λ = 3 和 λ = 8 时分别按“能量最低”。c₂ 和密度凹陷如何变化？

λ = 3 时 c₂ ≈ −0.27，凹陷 ≈ 68 %；λ = 8 时 c₂ ≈ −0.52，凹陷 ≈ 99 %。排斥越强，第二组态的权重越大，库仑空穴越深。
