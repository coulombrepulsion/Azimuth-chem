斯莱特–康登规则

两个斯莱特行列式之间的哈密顿矩阵元 ⟨Ψ|Ĥ|Ψ′⟩ 可化为若干单电子和双电子积分。用自旋轨道组装两个行列式——程序会将它们化为最大重合，判断属于哪种情况，并用 hij、Jij 和 Kij 写出结果。

需要理解的要点

  • Slater 行列式之间的矩阵元按 Slater–Condon 规则化为单电子和双电子积分。
  • 先把行列式调整到最大重合；每次交换两列都会改变符号。
  • 只有当两个行列式至多相差两个自旋轨道且 MS 相同时，矩阵元才可能非零。
  • 交换积分只出现在自旋相同的自旋轨道之间。

He，⟨1s²|Ĥ|1s²⟩：为什么结果中没有交换积分 K？

答案为 2h₁₁ + J₁₁。交换项只存在于自旋相同的自旋轨道之间，而 1sα 与 1sβ 自旋不同——对自旋积分使其为零。

H₂：⟨σg²|Ĥ|σu²⟩ 等于多少？它起什么作用？

两个自旋轨道不同，答案为 K₁₂ = (12|12)——σg 与 σu 之间的交换积分。这是 CI 矩阵的非对角元，它使 σg² 与 σu² 混合，从而修正解离行为。

从闭壳层 1s² 出发的单激发 1β → 2β：矩阵元等于多少？为什么对 HF 轨道它为零？

h₁₂ + (11|12)——这是 Fock 算符的矩阵元 F₁₂。哈特里–福克轨道使 F 对角化，因此 F₁₂ = 0：布里渊定理。

|1α 2α 3β| 和 |3β 1α 4α|：需要几次对换？符号如何？

对换次数

将 3β 从第一位移到第三位——两次对换，符号为 +。之后只有一个自旋轨道不同：2α → 4α。

|1α 1β 2α| 和 |1β 1α 2α| 是同一个行列式吗？

在相差一个符号的意义下是同一个函数：一次对换给出因子 −1，矩阵元等于 −E。因此在计算 CI 矩阵之前必须固定列的顺序。

为什么 ⟨|1α1β||Ĥ||1α2α|⟩ = 0，尽管只有一个自旋轨道不同？

替换 1β → 2α 改变了自旋。Ĥ 不作用于自旋，自旋积分 ⟨β|α⟩ = 0。只有 MS 相同的行列式才会混合。
