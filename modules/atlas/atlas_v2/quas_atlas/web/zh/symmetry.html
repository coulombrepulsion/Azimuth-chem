分子点群

选择一个点群。可用鼠标或手指旋转模型。右侧依次为：带动画的对称操作类、含中心原子轨道的特征标表、按不动原子计算 Γ₃N、分子振动以及乘法表。下方展示取代或畸变时点群如何降低，以及各类对应到哪里。

需要理解的要点

  • 点群是分子所有对称操作的集合；根据对称元素确定（Schoenflies 流程）。
  • 共轭操作组成一个类；不可约表示的数目等于类的数目。
  • 不可约表示的特征标表明轨道、振动以及函数 x、y、z 在群操作下如何变化。
  • 约化公式回答“有多少、是哪些”的问题：振动、SALC、分裂后的子能级。
  • 由配体轨道张成的表示，其特征标是不动的配体数；约化公式把它分解为不可约表示，投影算符给出 SALC。

对称性降低

只有当改变后的分子在操作后与自身重合时，该操作才保留在群中。因此新群总是原群的子群，而且它的每个类都完整地包含在某个旧类之中。

检验你的知识

页面练习：先在页面上操作，再选择答案——答案会立即检查。

打开 Oh 的“类”选项卡。3C₂（= C₄²）和 6C₂ 都是绕轴旋转 180°，为什么属于不同的类？

3C₂ 是绕坐标轴（即 C₄ 所在的轴）的旋转，而 6C₂ 是绕通过相对棱中点的轴的旋转。群中没有任何操作能把第一类轴变成第二类轴，因此这些旋转不共轭，构成不同的类。

Oh → “沿 z 轴拉长”。3C₂ 类变成什么？

变成 C₂（绕 z 旋转）和 2C₂′（绕 x 和 y 旋转）。拉长后 z 轴不再与 x、y 等价，原来的类分裂为两个。

Td（CH₄），“Γ 计数”选项卡。红外光谱中有几个谱带？拉曼光谱中有几条谱线？

Γ振 = A₁ + E + 2T₂。只有 T₂（与 x、y、z 同）具有红外活性——2 个谱带。A₁、E 和两个 T₂ 均具有拉曼活性——4 条谱线。

C3v，“乘法”选项卡。比较 C₃·σv 和 σv·C₃ 两个格子。它们说明了什么？

两个乘积都是反映，但反映面不同：C₃ 与 σv 不对易，C3v 群是非阿贝尔群。书写顺序很重要：在 A·B 中先执行 B。

D4h（[PtCl₄]²⁻），“特征标表”。哪个 d 轨道属于 b1g，哪个属于 b2g？这取决于什么？

dx²−y² 属于 b1g，dxy 属于 b2g。这源于约定：C₂′ 轴通过配体，即沿 x 和 y 方向。若将坐标轴旋转 45°，两个标记就会互换。

“可约表示与 SALC”：CH₄ 中氢的 1s 轨道分解为哪些不可约表示？

A₁ + T₂：Γ = (4, 1, 0, 0, 2)；约化公式给出 n(A₁) = (4 + 8 + 12)/24 = 1，n(T₂) = (12 + 12)/24 = 1。它们与碳的 2s（A₁）和三个 2p（T₂）成键。
