原子光谱项

同一个电子组态，例如 2p²，对应若干能量不同的状态——光谱项 2S+1L。它们由微观状态求得：在遵守泡利原理的前提下，列出电子在自旋轨道上的所有排布方式，并按 ML 和 MS 分组。基态光谱项由洪特规则给出。

需要理解的要点

  • 一个组态对应若干能量不同的谱项 2S+1L。
  • 谱项通过微观状态表求出：每个谱项占 (2L + 1)(2S + 1) 个状态。
  • 对等价电子，Pauli 原理禁止部分谱项。
  • 基谱项由 Hund 规则给出：S 最大，其次 L 最大，再按壳层填充情况确定 J。
模型的适用范围：LS 耦合与洪特规则
计算的是什么
组态的微观状态、光谱项的分解、基态光谱项。
采用了哪些近似
Russell–Saunders 方案（LS 耦合）；不计算自旋–轨道分裂为 J 能级。 对于有多个开壳层的组态（如 3d²4p），确定基谱项的洪特规则并不可靠。
能得出什么结论
在 LS 方案中光谱项的集合是精确的；洪特规则预测基态光谱项，但不预测激发态的顺序。

2. 由洪特规则求基态光谱项

1) 多重度最大：电子以平行自旋占据不同的轨道。2) 在此前提下 L 最大：从最大的 ml 开始填充。3) 若亚层不到半满，J = |L − S|；若超过半满，J = L + S。

p² 组态有多少个微观状态？

微观状态数

6!2! · 4! = 15：两个电子不重复地分配到六个自旋轨道上（泡利原理）。

p² 组态给出哪些光谱项？

¹D、³P 和 ¹S：5 + 9 + 1 = 15 个微观状态。对于等价电子，¹P、³D 和 ³S 被泡利原理禁止（与第 1 部分中的 2p¹3p¹ 比较）。

碳原子基态光谱项中 J 等于多少？

J

J = 0：光谱项 ³P₀。2p² 亚层不到半满，因此 J = |L − S| = |1 − 1| = 0。

d² 组态有多少个微观状态？

微观状态数

10!2! · 8! = 45。它们分解为光谱项 ¹G、³F、¹D、³P、¹S；基态为 ³F（如 Ti²⁺ 和 V³⁺）。

铁原子基态光谱项中 J 等于多少？

J

J = 4：光谱项 ⁵D₄。3d⁶：五个电子自旋向上、一个向下，S = 2，L = 2；亚层超过半满，因此 J = L + S = 4。

为什么氧的基态光谱项是 ³P₂，而碳是 ³P₀？

O 的 2p⁴ 亚层超过半满，按洪特第三规则 J = L + S = 2。C（2p²）不到半满，J = |L − S| = 0。p² 和 p⁴ 的光谱项相同，只是 J 能级的顺序不同。
