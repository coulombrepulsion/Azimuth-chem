变分法与微扰理论

薛定谔方程只对少数体系能精确求解，因此量子化学依靠两种近似方法。变分法给出的能量永远不会低于精确值：E[φ] = ⟨φ|Ĥ|φ⟩⟨φ|φ⟩ ≥ E₀。Hartree–Fock 方法和 CI 都建立在它之上。微扰理论把能量按小微扰展开成级数；MP2 方法就基于它。

需要理解的要点

  • 变分原理：任何试探函数的能量都不低于精确的基态能量，因此两个函数中能量较低的一个按这一标准更好。但这并不意味着它的密度、偶极矩或核附近的行为更准确。
  • 线性变分法（久期方程）是 Hartree–Fock–Roothaan 方法和 CI 的基础；如果新基组包含旧基组且哈密顿量不变，能量只能降低。换用另一个基组或对于非变分方法（例如 MP2），则没有这种保证。
  • 微扰理论按阶展开能量：E(1) 是微扰的平均值，基态的 E(2) 为负。
  • 微扰级数在微扰小时效果好，微扰大时可能发散；MP2 是相关能的二阶微扰。
模型的适用范围：能量的上界，而不是所有性质的精度

找出高斯试探函数的极小。能量是多少 Eh？

E, Eₕ

Emin = −43π ≈ −0.4244 Eh，此时 α = 89π ≈ 0.283。比精确能量高 0.076 Eh（约 47 kcal/mol）。

变分能量可能低于精确基态能量 −0.5 Eh 吗？

不能：对于任何容许的试探函数 E[φ] ≥ E₀——这就是变分原理。因此，在同一哈密顿量下的两个变分计算中，能量较低的那个更好地逼近基态能量。但其密度或偶极矩不一定更准确。

第 2 节绿色曲线：向基组中添加函数时误差如何变化？

减小，但始终为正：能量从上方逼近精确值。N = 4 时误差小于 1 kcal/mol；之后每增加一个函数带来的改进越来越小。

非谐振子，n = 0，λ = 0.1：微扰理论效果如何？

很好：精确能量 0.5591，一阶给出 0.575，二阶给出 0.5488。两者都接近，二阶略好。

λ = 0.2 时 n = 0 的一阶修正 E(1) 是多少？

E⁽¹⁾

E(1) = λ⟨0|x⁴|0⟩ = 3λ4 = 0.15。这就是微扰在未微扰基态中的平均值。

对 n = 0 增大 λ。微扰级数会怎样？

大约从 λ ≈ 0.16 起，二阶的误差已经比一阶大：修正 E(2) ∝ −λ² 的增长快于一阶误差的减小。x⁴ 的级数是渐近级数——对任何 λ > 0 最终都会发散。

试探函数 A 的能量低于函数 B。哪一个给出的偶极矩更接近精确值？

根据这些数据无法判断。变分原理只限制能量：函数的一阶误差只带来二阶的能量误差，而偶极矩对函数的误差是一阶敏感的。能量较低的函数可能对其他性质描述得更差。
