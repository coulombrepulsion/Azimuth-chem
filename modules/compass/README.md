# Азимут · Компас

Запуск из корня программы: `python -m modules.compass` интерпретатором из .venv.

Назначение и общий контракт: ../../docs/MODULES.md.
История изменений: ../../CHANGELOG.md.
Общее ядро остаётся в azimuth; самостоятельный запуск не означает отдельный дистрибутив.

## Папки (0.105.17)

- `workspace.py` — Компас целиком (CompassWorkspace собирает части из папок ниже).
- `actions/` — части окна: меню, инструменты и их окна (`*_actions.py`, `pictures.py`).
- `chemistry/` — химия без Qt: построение и выравнивание, конформеры, кристалл, симметрия, названия, форматы, библиотека (`library.json`), RDKit (`rdkit_embed.py` запускается отдельным Python).
- `view/` — поле модели: рисование (QPainter, попиксельная глубина, VTK), схемы, наложения, картинки и GIF.
- `panels/` — страница структуры, выдвижные панели, документы, таблица Менделеева, мелкие виджеты.
