# Азимут · Спектр

Запуск из корня программы: `python -m modules.spectrum` интерпретатором из .venv.

Назначение и общий контракт: ../../docs/MODULES.md.
История изменений: ../../CHANGELOG.md.
Общее ядро остаётся в azimuth; самостоятельный запуск не означает отдельный дистрибутив.

## Папки (0.105.17)

- `workspace.py` — Спектр целиком.
- `readers/` — чтение выводов программ (ORCA, Gaussian, Psi4, xtb, MOPAC, NWChem, Q-Chem, GAMESS, CUBE, орбитали) и общая модель результата (`results.py`, `outputs.read_any`).
- `wavefunction/` — Multiwfn: запуски и их анализы (заряды, CDA, локализованные орбитали, QTAIM очереди, таблицы поля).
- `analysis/` — расчёты по результату без Qt: спектры, термохимия, плотность, орбитали, Фукуи, реакции, сравнение геометрий.
- `views/` — окна и страницы: спектры, термохимия, орбитали, плотность, поля, реакции, инструменты, колебания.
