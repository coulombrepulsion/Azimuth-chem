**Азимут {version}** — программа по квантовой химии: Атлас, Компас, Секстант, Спектр.

| Система | Файл |
|---|---|
| macOS на Apple Silicon | `Azimuth-{version}-macOS-arm64.dmg` — откройте и перетащите «Азимут» в «Программы» |
| Windows x64 | `Azimuth-Setup-{version}.exe` — ставится без прав администратора |
| Linux x86_64 | Source code (zip или tar.gz) — распакуйте и запустите `Launch-Linux.sh` из терминала |

`Azimuth-macOS-arm64.dmg` и `Azimuth-Setup-Windows-x64.exe` — те же файлы под именем без версии (на них ведёт кнопка сайта); SHA-256 — в файлах `.sha256` рядом.

Программа не подписана. Первый запуск: macOS — «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»; Windows — «Подробнее → Выполнить в любом случае».

Что нового — [CHANGELOG.md](https://github.com/coulombrepulsion/Azimuth-chem/blob/v{version}/CHANGELOG.md). Руководство — `docs/manual/Azimuth-manual-ru.pdf` (`-en`, `-zh`) и меню «Справка → Руководство».
