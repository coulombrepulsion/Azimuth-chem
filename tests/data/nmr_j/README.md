# Эталоны КССВ ЯМР (0.106.1)

```
.venv/bin/python tools/run_references.py nmr_j --programs orca
```

| Вход | Что проверяется |
|---|---|
| `ethanol_ssall_orca.inp` | этанол: экранирование и все КССВ H и C (`%eprnmr … { shift, ssall }`); три H вращающейся CH₃ в статичной геометрии — 2,1, 5,3 и 14,3 Гц к H CH₂, в среднем 7,2 Гц (триплет и квартет) |
| `c2h3cl_ssall_orca.inp` | винилхлорид: транс-, цис- и геминальная ³J/²J(H,H) — 16,0, 8,4 и −3,5 Гц (опыт около 14,6, 7,3 и −1,4) |

Посчитано ORCA 6.0.1 на компьютере пользователя 2026-11-08, PBE0/pcJ-1 после оптимизации в том же базисе. Блок `%eprnmr`
ORCA принимает только после координат (с блоком до них она остановилась: «nuclear properties are requested but no
coordinates have been read»).
