# Эталоны для Рамана (0.90)

Входные файлы — в `inputs/`; выводы считаются на компьютере пользователя:

```
.venv/bin/python tools/run_references.py raman
```

Скрипт находит ORCA и Gaussian так же, как Секстант, считает каждый вход во временной папке и кладёт сюда
только вывод (`<имя>.out` — ORCA, `<имя>.log` — Gaussian).

| Вход | Молекула | Что проверяется |
|---|---|---|
| `h2o_raman_numfreq_orca.inp` | вода (C2v) | активности и деполяризация Рамана ORCA (`NumFreq` + `%elprop Polar 1`); у неполносимметричного колебания деполяризация 0,75 |
| `h2o_analytic_freq_no_raman_orca.inp` | вода | ORCA 6.0.1 с аналитическими частотами (`Freq`) Раман не печатает: «Analytical Hessian not available for calculation of RAMAN spectra… choose NumFreq» — эталон для предупреждения |
| `ch2o_raman_numfreq_orca.inp`, `ch2o_raman_g.gjf` | формальдегид (C2v) | все 6 колебаний активны и в ИК, и в Рамане |
| `c2h4_raman_numfreq_orca.inp`, `c2h4_raman_g.gjf` | этилен (D2h) | правило альтернативного запрета: у центросимметричной молекулы колебание активно либо в ИК, либо в Рамане |
| `h2o_raman_g.gjf` | вода | Gaussian `Freq=Raman` |

Уровень везде B3LYP/6-31G(d), плотная оптимизация; у Gaussian `5D 7F` — сферические d, как у ORCA, чтобы
частоты и активности двух программ можно было сравнить между собой (независимая проверка разборщиков).
