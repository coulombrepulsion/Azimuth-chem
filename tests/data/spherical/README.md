# Порядок сферических функций NWChem и Q-Chem

Формальдегид в cc-pVTZ: на C и O есть сферические d- и f-функции. Молекула повёрнута произвольно, симметрия выключена,
поэтому ни одна компонента оболочки не обнуляется. Если программа читает функции оболочки не в том порядке, орбитали
перестают быть ортонормированными, а заряды Малликена расходятся с напечатанными программой
(`tests/spectrum/test_spherical_order.py`).

Посчитать (нужны NWChem и/или Q-Chem):

    .venv/bin/python tools/run_references.py spherical --programs nwchem,qchem

Выходы ложатся рядом: `formaldehyde_tz_nwchem.out`, `formaldehyde_tz_qchem.out`. Пока их нет, тест пропускается.

`formaldehyde_tz_nwchem.out` — NWChem 7.3.0 (conda-forge, macOS arm64), посчитан 2026-11-22; пути заменены на
`/opt/nwchem`. Он показал, что у NWChem сферические функции с нечётным m > 0 (m = +1, +3) взяты со знаком (−1)^m
(фаза Кондона — Шортли) против наших: без поправки отклонение C^T S C было 12. Порядок m = −l … +l подтвердился.
